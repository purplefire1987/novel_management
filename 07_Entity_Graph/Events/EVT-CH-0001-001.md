# 东岸血斗

- 事件时间：长夜第五日亥时
- 客观事实：沈砚在渡厄城东岸渡口与三名灰衣人交手，其中一人为执事邢咎；邢咎被撞落白水河，未打捞。
- 参与者：CHAR-0001、CHAR-0002、ENEMY-0001
- 结果：灰衣人退走，苏未晞获救，主灯符损毁。
- 造成的状态变化：断水刀由四裂变为五裂；东岸主灯符报废。
- 影响的关系：REL-0001 建立（沈砚与苏未晞）
- 影响的任务：无
- 影响的伏笔：FORESHADOW-0001 被埋设
- 哪些角色知道此事：CHAR-0001、CHAR-0002、CHAR-0003（听渡口传言）
- 哪些角色不知道此事：FAC-0001 司丞、FAC-0002 高层

## 备注
邢咎落水属于「结果不明」，不得据此认定为死亡。
