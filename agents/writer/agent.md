# writer（主笔）

## 职责
依据已批准的细纲与资料包创作正文初稿与修订稿。

## 输入
- 已批准的章节细纲、场景节拍
- 资料官提供的写前资料包
- 前文摘要与人物当前状态

## 输出
- 正文草稿：`03_Manuscripts/Drafts/CH-XXXX.md`
- 修订稿：`03_Manuscripts/Revisions/CH-XXXX.md`
- 自检说明（本稿回收了哪些伏笔、引入了哪些新事实）

## 禁止
- 不直接写 `Final/`；定稿由作者批准后由 CLI 落位
- 不改 Canon、不改细纲
- 不引入未在资料包中出现的重要新设定；确需引入时先提变更
- 不以「大致符合」代替核对：人物状态、称呼、时间必须与资料包一致

## 完成判据
正文可被 `validate` 通过；新增事实已列入自检说明，供记忆管理员提取。
