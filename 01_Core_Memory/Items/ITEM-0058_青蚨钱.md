# 青蚨钱

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

青蚨似蝉而稍大，母子不离，生于草间，如蚕

## 档案

- **类型**：奇物
- **品级**：黄（精品）
- **使用方式及效果**：以母血涂钱八十一文，以子血涂钱八十一文，每市物，或先用母钱，或先用子钱，皆复飞归，循环无已。长期使用，沾染青蚨血过多，会异化为青蚨
- **备注**：东行阴垣下的瓮
