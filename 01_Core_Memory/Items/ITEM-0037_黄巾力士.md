# 黄巾力士

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

帝国新一代列装的机甲则使用了不同思路，通用型主体加装配件来区分不同的功能，代号为“黄巾力士”，颈部有掺入了“首山铜”制成的围饰以支持新一代汽轮机的运作和散热，同时将灵流回路调整到整个背部并篆刻有超大型太玄盘以提升使用者的能力范围，动力机的保护也得到了加强，性能、战斗力和灵敏程度对比“力士”都获得了跃升，还可以通过加载强化部件进行部分机体强化（固定加载，有使用次数限制），同时黄巾力士的单次使用时间可达6个小时，而后需要整备散热。目前，帝国拥有大约1200台力士，黄巾力士150台，仅限于王牌小队才能使用。
