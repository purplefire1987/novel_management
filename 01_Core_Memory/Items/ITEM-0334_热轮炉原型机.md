# 热轮炉原型机

## 概要

明工造造到第三台的热轮炉样机，箱侧那行小字就是它的名字：**热轮炉·试作三号**。

兴元十二年七月初八夜，它被四个人从武安都的工坊里抬出去。箱子是照四个人抬的尺寸打的，
两个人抬着走，第三个在前头拽、两个在后头顶，脚在积水里打滑。抬箱的人一路上只有一句抱怨：

> 「太重了。图纸上不是说两个人抬得动？」

这台机器的第一个性格是这句抱怨给的——**图纸上轻，铁上重**。它还没露面，先让人吃了苦头。
