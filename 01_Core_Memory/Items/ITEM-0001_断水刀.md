# 断水刀

- 类型：旧制横刀，刀身有七道旧裂
- 来源：陆听寒失踪前留给沈砚
- 功能：可承载气，是沈砚唯一的承载物
- 使用条件：持刀者须以自身血为引，且气不得同时灌注他物
- 限制：每次承载会新增一道裂痕；七裂之后刀会断
- 当前持有者：CHAR-0001 沈砚
- 当前状态：已用五裂，刀鞘内侧有两道旧血痕（第二道来源未明，见 FORESHADOW-0001）
- 已知历史：长夜三十七年曾被带上西岸，之后由陆听寒交还沈砚
