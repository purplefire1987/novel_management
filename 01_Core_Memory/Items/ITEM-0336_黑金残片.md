# 黑金残片

## 概要

一块黑金的断片。「黑金」在九州首先是**矿料**的名字，最早从融金城挖出来（那城的备注里写着
「黑金矿坑：最早发掘出黑金的场所，曾有火山在此爆发」）；如今多处黑金矿山在扬州那头有人经营，
[[CHAR-0063_甄曦|甄曦]] 一系明面上做茶楼商行，暗里握着不止一座。

这块残片本身还没在任何正文里露过面。卷一大纲只留了一句：**陈默在仓库失窃案中首次接触。**
所以本卡先立着，等那一案写到再填。

## 档案

- **类型**：材料／矿料
- **品级**：未定
- **形制**：残片——断口、大小、成色**均未定**
- **来源**：黑金矿（最早见于融金城）
- **当前状态**：未登场

## 关联

- **矿脉**：融金城（黑金最早发掘地）——矿在城里，**残片不在**，故不作双链，免得地图把它挂上去
- **经手方**：[[CHAR-0063_甄曦|甄曦]]（名下有多处黑金矿山）——只是背景，不代表残片现在在她手上
- **卷纲**：[[VOL-0001_工坊疑云|卷一·工坊疑云]]（「陈默首次接触」一句的出处）
