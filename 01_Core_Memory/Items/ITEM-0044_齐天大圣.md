# 齐天大圣

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

由“志怪山人”吴汝忠主导研发，洪炉试验性汽轮机动试验兵器，创造性的运用了「灵-场」理论，使用应灵器来替代控制杆，驾驶系统则使用的是圆形感应舱体，通过应神骨架技术，被安置在腹部位置；不同于其他巨兵，大圣使用了多个动力源，基础动力源是紫霞Ⅱ型汽轮机，「灵-场」动力源则是染灵机（通过灵石供能，激发法符冲击使在机器内部将其放出的灵能直接转换为动力的灵力发动机）供能，其他动力源则是斗云Ⅱ型微型汽轮机，齐天大圣能够通过应灵器捕捉使用者的灵能波动并精细的操控汽轮机和染灵机的功率，姿态器则是采用的灵集阵列以提高准确度；大规模应用的灵流回路让控制精细度变得更加难以把握，染灵机也提高了对使用者能力的要求，同时在机体中成功的使用了特殊素材“五彩石”，如此特别的设计也使得少有人能使用这件划时代的兵器。特备武器是定海神珍铁——如意金箍棒，常备武器是重汽霰弹铳、速射机关铳、收缩钢匕首。“齐天大圣的设计者是个天才，因为它赋予了那些寻求力量之人希望，让一介凡身也可以在狂风中怒吼，和自然灾难搏斗，与那些强大修者交锋，修正扭曲、开辟未来！”大司空曾经这样盛赞这件兵器。目前齐天大圣的适格使用者是绰号“行者”的孙鑫源。齐天大圣有几个模式：超载模式，短时间提高出力的爆发模式；变形模式，可以变形为其他形态；毁灭模式，启动悟空系统（一种具有自我意识的系统，通过染灵机来激活）全面强化驾驶者，机体也将会全面提升，拥有新武器灵光炮，使用后需要重新充填。
