# 和璞

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

方圆四寸，上纽交五龙，又称“和璧”，岁星之精、青绿而玄，侧视色碧、正视色白，上刻“受命于天，既寿永昌”

## 档案

- **类型**：奇物
- **品级**：玄（名器）
- **使用方式及效果**：在100尺范围内，获得“普天之下莫非皇土”效果。气运较低时，会遭到反噬
- **备注**：帝室的传承之宝。放置于始皇帝亲篆秘封金盒。
