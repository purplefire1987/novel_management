# 巨灵神

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

帝国特制超巨型汽动装甲机兵，地上速度120千米/时，姿态变幻时间2秒，可以短暂飞行和滞空。在机体材料上则是使用融合“首山铜”与“神珍铁”的特殊合金，在机体的设计上大幅提高了动力和灵活性，虽然仍然使用控制杆操作，但巨灵神本身也进行了特殊的灵流回路设计，它能通过特别携带的灵晶激发器和特殊镌刻的玄符铜板（灵能插件，机体自带插槽仓）以使机体获得不同的神通（例如：锁定、不屈、铁壁、超速、霸体、专注、扭曲）。巨灵神的驾驶座在心脏部位，使用的是潜望镜观察系统，使得驾驶者的安全性得到了更大的提升，拥有汽动武器（重压打桩机、灵晶汽炮，锯齿切割刀）。目前为止，帝国仅有6台巨灵神。
