# 紫焰蛇矛枪

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

多称火尖枪，中间的枪尖是弯曲形，两边尖头状似牛角形。有蛇嘴，蛇眼发光，上下有小蛇盘旋。枪缨是一团紫色火焰，枪嘴和枪尖能喷吐云雾。枪身有蛇纹图案缠绕，枪长一丈八，蛇尾型枪纂，共有两杆，可合二为一
