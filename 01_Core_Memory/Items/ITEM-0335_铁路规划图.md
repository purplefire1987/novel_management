# 铁路规划图

## 概要

一卷油布包着的图纸，封皮上一行朱字，灯光一照亮得刺眼：**铁路规划**。

它藏在武安都明工造工坊正室的砖后暗格里。兴元十二年七月初八夜，绿罗会的杀手杀了老坊主
安怀舟，只为从暗格里抽出这一卷——暗格里其余文书一件没动，连位置都没挪，走时还把暗格复原了。

> 「因为他只要一样东西。他知道那东西在哪儿，知道暗格怎么开。他知道，所以不用翻。」

杀人是手段，取图是目的。卷一的整个案子，就是从这条判断上拧开的。

## 说明（总管补注）

作者 2026-11-06 授权「可由总管制草案」，此卡为 **proposed**。

**图上画的是什么，全库都还没写。** 只写到「盖着朝廷大印」「铁路规划」六个字。所以本卡不列线路、
不列里程、不列工期——这三样一旦写死，后文所有关于铁路的段落都得跟着改。等正文第一次展开图纸时再补，
届时最好与 [[WORLD-0040_行政区划表|行政区划表]] 的州府对应着画。

**「归属」与「去向」分开记**：`归属` 是写得出证据的那一手（绿罗会当夜取走），去向是卷一大纲的意图
（冬河会）。混成一条会让 [[FAC-0050_冬河会|冬河会]] 的关联物品里多出一件正文还没交代的东西。
