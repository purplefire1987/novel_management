# 天衣

## 概要

蓬莱制造的号称“活着”的战斗服，添加了特殊素材，主要核心是“素带”，“素带”可以为使用者在战斗中提供额外的灵力和个人属性，天人道服可以完美与修者融合灵力闭环，并让使用者更轻易的使用能力、获得增幅放大，因而造价不菲且产量不高。“天衣”还拥有固化的大范围法术，同时具有隐匿、自我清洁、防护术等，仅需要少量的灵力即可维持。

## 档案

- **类型**：装备/防具/胸部
- **品级**：仙人道服
- **使用方式及效果**：长时间使用可能导致逐渐丧失情感
