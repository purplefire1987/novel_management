# 石犀牛

> 来源：`九州-世界观资产.xlsx` · 工作表「物品库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

一丈长的犀牛形状的石雕，躯干丰满壮实，四肢粗短，下颌及前肢躯干部雕刻重山纹

## 档案

- **类型**：奇物
- **品级**：黄（精品）
- **使用方式及效果**：石犀牛长时间暴露，会逐渐抽干周围的水汽，形成无水之地
- **备注**：古代人所做厌水之物，在数百年的岁月中变成了奇物，需要放在纯净的水之中
