# 海牛铁甲舰

## 概要

海岱曾经的最大民间造船商“熔盛重工”生产的试验性汽轮铁甲船 ，船头为撞角，涂装似牛，船身有全覆式铁甲，甲板上还有可升起的遮盖铁板保护船上设施。船上依照甲板划分舱室，顶层甲板为露天舰桥、驾驶室（罗盘针）、海图室、高级船员室、排烟管，上层甲板为船员室、棋牌室、工程室、炮弹房、锚机、舵机，中层甲板为厨房、医疗室、大餐厅，下层甲板为火工室、大仓库（生活物资），船底为锅炉、轮机、燃料室、水压舱以及传动系统。
