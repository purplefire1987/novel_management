# 终南山会

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

产生于第四纪中期，学派信奉“清净”等思想，追求自然之真和大道之理，希求人可长生，寻求超脱之法，因此被称为“长生隐修会”；隐修会初代首领于终南山隐世，他的追随者们又别称为“终南山会”。乌角道人、南华仙均是其中的分支。

## 档案

- **势力所属**：长生学派
- **阵营**：民间
- **据点**：西陵城
- **信物**：黄帝阴符宝箓、混元阳符神箓
- **关联技能**：太平要术,金丹仙经,周易参同契,柳叶金刀
