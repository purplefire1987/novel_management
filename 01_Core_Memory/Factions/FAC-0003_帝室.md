# 帝室

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

帝国崛起于第四纪元某期，前身是人族部落——夏氏。上古时代结束后，人族开始划分势力范围，聚集领民，休养生息，这些势力被称作部落。在第四纪的中期，随着部落之间的逐渐壮大， 他们不可避免的开始了互相征伐、争夺大陆霸权的战争。在这个过程中，夏氏迅速的崛起了，并最终统一了整个九陆，其帝国象征变成了“盛龙”

## 档案

- **势力所属**：帝室
- **阵营**：朝廷
- **据点**：白玉京
- **信物**：皇朝金令
- **信物简介**：巴掌大小的令牌，由“玄铁木”雕刻而成，镶嵌“魂纹铜钉”，通体浮刻“九爪金龙”，龙首衔“盛”字古篆，尾部为错金玄纹，每一块皆由内务府所标注
- **势力特色**：泰山封禅、力士（力士、黄巾力士、巨灵神、金人）、印绶、祥瑞合成技术
- **势力仪式**：“此泰山上筑土为坛以祭天，报天之功，故曰封。此泰山下小山上除地，报地之功，故曰禅”。自泰山之阳登山，在岱顶行登封礼，建封坛，高九尺，并立石颂德，其下埋藏玉牒书。自泰山之阴下山，行降禅礼于梁父山。
- **关联技能**：皇极经世功
