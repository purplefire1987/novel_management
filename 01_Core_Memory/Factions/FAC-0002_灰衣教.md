- 地盘：白骨渡西岸废祠一带
- 敌对势力：镇夜司
- 盟友：不明（有渡口行会内线）
- 内部矛盾：长老之间争夺「换命」名额
- 当前状态：近期在西岸频繁活动，与多起失踪案相关
