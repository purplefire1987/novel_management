# 黑旗船团

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

由破产渔民、逃犯、欠债船匠组成的海上盗贼，采用了联盟制，拥有极强的改装能力，熟悉险海，暗礁、季风与秘密水道是其对抗官方的本钱，入伙必须有人担保。后期接受了冬河会投资。

- **势力所属**：海商,冬河会
- **阵营**：民间
- **据点**：浮光城,骷髅岛
- **信物**：黑旗
- **信物简介**：这是一面特制的黑旗
- **核心利益**：劫掠货船、收取过路钱、走私，保护隐秘淡水岛和船坞，为团众争取可持续的生计
