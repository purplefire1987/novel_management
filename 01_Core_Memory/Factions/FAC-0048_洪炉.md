# 洪炉

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

作为以推翻帝国为目标的组织，正筹划着一系列的叛乱计划。洪炉分为3大支部（每个支部人数不等，最多的支部为行动队），各支部人手已经渗入了各大组织，之前已经被帝国追捕的是活跃在戎州，与妖族叛乱军有紧密联系的“赤炉”部。洪炉的总部在中州的隐藏洞天“平都山”，在第一卷中正在筹备钟鸣计划。钟鸣计划是指建造东皇钟用来轰击上京城。具体作战计划由合议会决定，组织结构则分为干部（炎锋），组长（炽刃），队员（星火），外围（余烬），
