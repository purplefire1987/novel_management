# 行者堡垒

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

产生于第四纪中期，提出了“兼爱”、“非攻”等思想，因早期成员多源自工匠，又被称为工匠学派。其组织严密，首领被称为巨子，由组织中公认的贤者们互相传让，但由于思想不利于帝国的统治，故在夏氏统一帝国后成为隐世组织，成员被称为“行者”。“行者”主张苦修、冥想，注重实践，主修武术及机关术，擅长利用“机关”，多数行者居住于墨家世代修建而成的“机关堡垒”中，机关堡垒内有“俑兵”拱卫。
