# 东星帮

## 概要

武安都码头上的小帮派，靠看场、护船、抽头与替人办事吃饭，人数不多，但在楚河沿岸的船工、脚夫里有人缘。
帮主 [[CHAR-0015_吴山涛|吴山涛]] 出身湖州码头工，因能打而聚起一帮兄弟立了字号。

## 档案

- **势力所属**：帮派
- **阵营**：民间（黑道）
- **据点**：[[LOC-0057_武安都|武安都]]·楚河沿岸码头（详见「地盘」一节）
- **规模**：小帮派，数十人；核心是码头工与无籍流民
- **营生**：看场、护船、抽头、代客「办事」
- **帮主**：[[CHAR-0015_吴山涛|吴山涛]]

## 地盘

楚河贯穿武安都，两岸栈桥相连。东星帮的势力范围是**楚区一侧的货运码头与栈桥口**——
[[LOC-0057_武安都|武安都]] 四区之中，楚区（楚河以西）是商业区与内陆港口，漕帮把持大宗，东星帮只在缝隙里做小账：
替商号盯货、替船主平事、替不愿露脸的人「找个人」。

## 卷一中的行动

- **受托**：宫中仇敌下达追杀令，一名被称作「贵人」的雇主出钱，要东星帮在武安都截住出逃的 [[CHAR-0002_项月溪|项月溪]]。
  帮主接单时只知「一个十六七岁的女学生，青衣素冠」，不知其皇女身份。
- **误判**：兴元十二年七月初八夜，帮众在武区街巷截住目标，误以为是要抓的逃犯，追至 [[LOC-0057_武安都|武安都]]·明工造工坊附近。
- **撞场**：同一夜绿罗会正在工坊内行凶、洪炉在搬东西，东星帮的追捕成了现场第三路人马；
  靖卫司封控后，帮众四散，只留下「谁雇的」这条线没断。
- **线头**：帮主与「贵人」之间只有中间人递话，没见过正脸——这是卷一留给后文的接口。
