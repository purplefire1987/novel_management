# 靖卫司

## 概要

大盛帝国掌**城防、治安与城内刑案**的官署，隶**吏部**。州、府、郡、县各有分支，
从「靖卫使」到「巡捕」一条线到底，管的是城墙以内的事——巡夜、缉捕、封控、初审、押解。
城外野地里的事归卫戎军，修士的事另有一套（玄部与镇灵台）插手，靖卫司只到通明境以下。

## 档案

- **势力所属**：官署（帝国中枢机构）
- **上级**：吏部（大宰统辖）
- **主官**：靖卫大统领（从三品，中央）
- **职掌**：
  - **城防**：城门启闭、城垣巡守、坊市门禁
  - **治安**：巡夜、缉捕、械斗与盗案的处置
  - **刑案**：城内命案与窃案的现场封控、初审、押解、卷宗上报
  - **消防**：与潜火府协同
  - **低级修士管理**：通明境以下修士的登记与管束

## 与其它衙门的分界

- **卫戎军**：城外的野战与要地守备；靖卫司只管城墙以内，两者在城门处交接。
- **镇灵台 / 玄部**：通明境以上的修士与灵异事件归他们；靖卫司遇到就上报，不自行处置。
- **刑部 / 大理寺**：靖卫司做的是**现场与初审**，定罪与覆核在上面两级。
- **潜火府**：消防专责，与靖卫司同属靖卫大统领节制。

## 在卷一中的行动

- **封控**：兴元十二年七月初八夜接报明工造工坊出事，外围封控、破门盘查（[[CH-0001_雨夜的血案|CH-0001]]）。
- **初审**：把现场唯一说不清来历的活口 [[CHAR-0001_陈默|陈默]] 作为「临时关联人」带回。
- **场所**：武安都靖卫司衙门设「观留室」（等候与初问）与「暂审间」（留置审讯）；
  陈默被安置在**六号暂审间**（[[CH-0002_石季崇的试探|CH-0002]]）。
- **办案逻辑**：案子必须有人签字负责——[[CHAR-0004_石季崇|石季崇]] 在案卷上签字，工坊进入封控与侦察状态。

## 说明（总管补注）

作者 2026-11-04 裁定：靖卫司**隶属吏部**，主要职责为**城防、治安管理、打击城内犯罪**。
此口径与 [[WORLD-0027_帝国官职表|帝国官职表]] 原有记载一致（靖卫大统领一栏即注「吏部」，职掌含「警备、城防、消防、低级修士管理」）。
