# 珞珈学院

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

珞珈学院是前朝一位为兴文振教的太守所创办。学院创立的宗旨在于传承文脉、弘扬学术，摆脱门第界限，响应“有教无类”的教育理念 ：贵族与平民皆可依才入学、共同求知。在学院创立之初，山脚隐有古寺供诗书讲论，后被改筑为讲堂，食堂聘请名厨轮换菜系，处处体现尚贤达人的精神。

- **关联技能**：月华流昭
