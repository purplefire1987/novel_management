# 十二连环寨

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

前身是长歌行，产生于第五纪中期，吸收了行者和兵家思想的实践者，早期多是北地燕赵之士，这些人慷慨激昂，重视义与诺，以武践行自身的正义——“义之所在，赴火蹈刃，死不足惜”，因而这个学派的修者又被称为“侠客”，他们擅长“内力”，经过锻炼的意识可以约束灵力在体内流动，并疏通人体奇经八脉，任督二脉形成回路，不同的回路形成了不同的体术流派，强大的侠客能使内力附在他们长期使用的兵器之上，大幅增强兵器的锋锐度和攻击力。长歌行有长歌行∙朝露/春德/百川数种修炼法，同时对其他修者的修炼法并不约束，现在的大本营是凉州的十二连环寨。侠士们共修神府和黄庭、肉身。镇寨绝学武经七书威震四海，拳棍刀剑皆有所长，有天下武功自此处出的说法
