# 冬河会

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

产业巨头、银团、风险投资公司、走私交易商、特许经营集团…明面上是财团，是财阀们的谈判之所，是巨额财富的汇聚之所，暗地里却是谋求帝国影响力的隐秘黑手之一。最初是由几个富豪家族所建的享乐场所，随着巨商们的加入，这里的影响力也不断扩大，其标卡也逐渐变成新兴富豪们的资产标志，明面上的会员等级分为银标、金标、紫金标。这些新兴的权贵们，则被老派贵族们鄙夷的冠以“帝国蛀虫”的称谓。由于九州商人地位较低，为了寻求更多的政治权力和影响力，他们一直在试图渗透帝国的官员，负责这方面行动的是冬河会内部的【黑金馆】，冬河会高层均持有冬河币，并成为帝国很多事件的幕后黑手。冬河会现在分为两大派别——维新派和立宪派，因为越深刻的与帝国接触，越了解帝国是何等样的庞然大物，帝国看起来是如此的坚不可摧。冬河会是很多帝国大事件的幕后黑手。

## 档案

- **势力所属**：行会,冬河会
- **阵营**：民间
- **据点**：岭南都
- **信物**：冬河币
- **信物简介**：黄金铸币上刻有冬日长河，币上有超微型机关，是冬河会的最高信物，总计有8枚，由最高会员掌握，据说破解机关可以找到冬河会隐藏的宝藏。
- **势力特色**：山海异兽
