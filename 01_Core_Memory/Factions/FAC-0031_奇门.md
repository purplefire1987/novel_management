# 奇门

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-213707`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

产生于第四纪初期，其最出名的是“最高预测之学”，原是从长生隐修会分裂，研究以术数之法归纳和推衍未来之事，用以预测吉凶，为前进而指引道路；奇门研究的是因果之学、预见之学，其术精微幽深，非天赋之辈不得入门，故奇门成员“门徒”并不多见；奇门最强盛之时，门徒不过7人，但其智足以左右世间局势。如今已经衰弱不堪，数百年未见有门徒出世，后世多有人以该学派为名欺骗世人以牟利。门徒们只修神府，有特殊的修习法。
