# 帝室

## 概要

帝国崛起于第四纪元某期，前身是人族部落——夏氏。上古时代结束后，人族开始划分势力范围，聚集领民，休养生息，这些势力被称作部落。在第四纪的中期，随着部落之间的逐渐壮大， 他们不可避免的开始了互相征伐、争夺大陆霸权的战争。在这个过程中，夏氏迅速的崛起了，并最终统一了整个九陆，其帝国象征变成了“盛龙”
