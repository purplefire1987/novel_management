# 环之教派

> 来源：`九州-世界观资产.xlsx` · 工作表「势力库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

教派的使命是毁灭世界，回归永恒的终环，信条“万物为轮，终而复始，众生沉沦，唯环可救”，主要活动包括煽动、召唤邪教，教派下有太始环、血狱环、衔尾环、千机环，各自负责不同的事项

## 档案

- **势力所属**：环之教派
- **阵营**：民间
- **据点**：云阙城
- **信物**：九劫齿
- **信物简介**：九根错齿齿轮叠列为环，齿上铭刻古老星语，由星铁碎片锻造
- **势力特色**：秽主祭
- **势力仪式**：建立九环阵（每环对应一类生命形式）；献祭指定阶级的生命；用“九劫齿”定位空间并触发星界裂隙
- **关联技能**：太初拓脉
