## 1. 派生数值

战斗力由角色以下部分的组成：（1）基本属性和境界；（2）技能：修炼法、技艺和神通；（3）其他：装备、物品、角色当前状态等

| 派生值          | 公式                               | 说明                                          |
| ------------ | -------------------------------- | ------------------------------------------- |
| **生命值 HP**   | 体质 × 2 + 境界加值 G                  | 境界加值 G = 3×（阶−1)²，见一·3.2.1（启灵 +0 … 玉真 +192） |
| **灵力值 MP**   | 灵元 × 2 + 境界加值 G                  | 施法消耗（见一·3.3 消耗表）                            |
| **灵膜**       | 灵元 × 1                           | 灵力护盾，受击先扣灵膜再扣 HP；MP=0 时灵膜消失                 |
| **AC（护甲等级）** | 50 + 体质 ADJ + LB + 防御技艺加值 + 装备加值 | 静态防御，攻击须 ≥ AC 才命中（见四·4）                     |
| **先攻**       | d100 + 体质 ADJ + LB               | 开战时掷，从高到低行动                                 |
| **移动速度**     | 30 尺（固定）                         | 该速度为凡人速度，技艺可提供移动加值。具体由 GM 描述                |
| **神通点**      | 0（初始）                            | 通明境起通过特殊知识/事件获得                             |
| **气运点**      | 初始 1（命格可调）                       |                                             |
| **功德点**      | 初始 0                             |                                             |

> **防御技艺**：闪避/格挡/护体类技艺（如「闪避」「铁布衫」「金钟罩」「护身罡气」），其等级加值计入 AC。无防御技艺则 AC = 50 + 体质 ADJ + LB（裸防）。**装备加值**：护甲/盾牌等提供，见数据库「物品库」。**防御型神通**（响应/护身类）可作为反应发动：对本次攻击 AC + 神通加值×2。

## 2. 调整值

调整值分为属性调整值（ADJ）、等级加值（LB）和技艺等级加值（SKB）。属性值随修炼提升，等级带来通用底子，技艺精熟带来专项加值——三者叠加构成全部检定加值。

### 2.1 属性调整值（ADJ）

属性值派生出「属性调整值」，用于先攻、命中、伤害、豁免及其他需要属性修正的检定。：

属性调整值公式

> **ADJ =（属性值 − 10）÷ 5，若出现小数，则向下取整**（可为负）。

| **属性值** | **10** | **30** | **50** | **70** | **90** | **110** | **130** | **150** | **175** | **200** |
| ------- | ------ | ------ | ------ | ------ | ------ | ------- | ------- | ------- | ------- | ------- |
| **ADJ** | \+0    | \+4    | \+8    | \+12   | \+16   | \+20    | \+24    | \+28    | \+33    | \+38    |

### 2.2 等级加值（LB）

**等级加值**是对所有"境界通用"动作生效的加值——武器、技艺、豁免、对抗、灾劫、神通、仪式，检定统一加 LB；**LB 同时计入伤害**。LB 随**等级**平滑成长、随**境界**跳档：

> **LB = 5 × 境界阶 + ⌊（当前等级 − 境界起始级）÷ k⌋**（若出现小数，则向下取整；k 为该境界的"每 k 级 +1"系数）

| 境界 | 阶 | 起始级 | k（每 k 级 LB+1） | 入门 LB | 峰值 LB       |
| -- | - | --- | ------------- | ----- | ----------- |
| 启灵 | 1 | 1   | 2             | \+5   | \+9（10 级）   |
| 培元 | 2 | 11  | 2             | \+10  | \+14（20 级）  |
| 玄灵 | 3 | 21  | 4             | \+15  | \+19（40 级）  |
| 真阳 | 4 | 41  | 4             | \+20  | \+24（60 级）  |
| 通明 | 5 | 61  | 4             | \+25  | \+29（80 级）  |
| 先天 | 6 | 81  | 4             | \+30  | \+34（100 级） |
| 造化 | 7 | 101 | 5             | \+35  | \+39（125 级） |
| 洞玄 | 8 | 126 | 5             | \+40  | \+44（150 级） |
| 玉真 | 9 | 151 | 5             | \+45  | \+49（175 级） |

> 例：玄灵 25 级 → LB = 5×3 + ⌊(25−21)÷4⌋ = 15+1 = **+16**。凡人无境界，LB +0。

> **相邻境界的 LB 关系**：级内每 k 级 +1（平滑）；**破境跳档**——本境峰值与下一境入门只差 **+1**（如玄灵峰值 +19 → 真阳入门 +20），但同一境界内从入门修到峰值共 +4，故每跨一境的总差距为 **+5**。

### 2.3 技艺等级加值（SKB）

**技艺等级加值**是"具体技艺的精熟度"：每项技艺有 1–5 级，检定时加对应等级的加值：

| **等级** | **名称**     | **检定加值** |
| ------ | ---------- | -------- |
| 1      | 初学乍练       | \+5      |
| 2      | 略有小成       | \+10     |
| 3      | 登堂入室       | \+15     |
| 4      | 炉火纯青       | \+20     |
| 5      | 出神入化【登峰造极】 | \+25     |

技艺等级加值用于：**命中、伤害、专业技能检定**。

### 2.4 计算公式

- **命中**：`d100 + ADJ + LB + SKB（+ 神通加值×2，若该击为神通攻击）+ 境界压制修正 ≥ 目标 AC`——DC = 目标 AC。
- **伤害**：`伤害骰 + ADJ + LB + SKB（+ 神通加值×2，若为神通攻击）+ 境界压制修正`（LB 计入伤害）。
- **豁免**：`d100 + ADJ + LB（+ 神通加值×2，若以神通对抗）`——若该属性为本门**擅长豁免**，再 **+5**。
- **AC**：`50 + 体质 ADJ + LB + 防御技艺加值 + 装备加值`（防御型神通作反应：本次 +神通加值×2）。
- **先攻**：`d100 + 体质 ADJ + LB`。
- **境界压制修正**：攻击方与目标境界不同时，攻击检定与伤害各加 **±S**——攻击方每**高**过目标一道境界门槛取 **+S**，每**低**过一道取 **−S**，跨多道门槛**累加**（门槛值 S 见下表）。同境界为 0；豁免、先攻等非攻防检定不计压制。

| 境界门槛  | **启灵↔培元** | **培元↔玄灵** | **玄灵↔真阳** | **真阳↔通明** | **通明↔先天** | **先天↔造化** | **造化↔洞玄** | **洞玄↔玉真** |
| ----- | --------- | --------- | --------- | --------- | --------- | --------- | --------- | --------- |
| **S** | ±4        | ±3        | ±1        | ±6        | ±3        | ±15       | ±14       | ±15       |

> 例：玄灵修士攻击启灵修士（跨过 2 道门槛：玄灵↔培元、培元↔启灵），攻击与伤害 **+3+4 = +7**；启灵修士反击则 **−7**。

> **为什么各档 S 大小不一**：S 与各档天然差距（LB 跳档、上限差、额外攻击跳档）共同校准到目标胜率（见 2.5）。玄灵↔真阳档 S 仅 ±1，因为真阳的"每回合 2 次攻击"（四·5.2）已承担了大部分压制；先天↔造化档没有额外攻击跳档，故 S 高达 ±15。

> **LB 回答"这个人什么层次"，SKB 回答"这门手艺什么火候"，神通回答"这个人有多离谱"**——三者权重 1:1:2。攻防双方同加 LB（境界底子相互抵消），同水平者命中率恒约 50%；神通以双倍权重打破这个平衡，这是通明境后"神通决定上限"的机制落点。

### 2.5 越级挑战胜率表（设计基准 ）

**测试基准（复测须严格按此）**：

- **低境方**：本境界**满级**（峰值 LB）；体质 = 本级单属性上限；灵元 = 体质÷2（向下取整）。
- **高境方**：下一境界**刚入门**（1 级、入门 LB）；体质 = 低境上限 + 突破奖励 3 点（**尚未享受新境界上限**——刚突破者没有时间把属性修到新顶格）；灵元 = 体质÷2。
- 双方：攻击技艺 3 级（+15）、防御技艺 3 级（+15）、名器 1d12、**无装备加值**、无神通；先攻 = d100+体质ADJ+LB；大成功 ≥96（重击）／大失败 ≤05；单挑至一方 HP≤0。

| 对阵（低峰→高入门） | 门槛压制 S | 设计目标 |
| ---------- | ------ | ---- |
| 启灵 → 培元    | ±4     | 20%  |
| 培元 → 玄灵    | ±3     | 20%  |
| 玄灵 → 真阳    | ±1     | 5%   |
| 真阳 → 通明    | ±6     | 10%  |
| 通明 → 先天    | ±3     | 5%   |
| 先天 → 造化    | ±15    | 1%   |
| 造化 → 洞玄    | ±14    | 1%   |
| 洞玄 → 玉真    | ±15    | 0.1% |

> **设计分工**：境界压制由四管承担——**境界压制修正 S**（上表，显式机制）、**LB 差**（峰值 vs 入门 +1，见 2.2）、**ADJ 差**（+3 属性 ÷5）、**额外攻击差**（4/6/9 境跳档，见 5.2）。境界加值 G 只管耐久（HP/MP），不承担直接的战斗压制。若日后调整（如改动额外攻击表），须用同一基准重跑本表。

## 3. 回合与先攻

- 战斗按**回合**进行，每回合约 6 秒（一息）。
- **先攻**：开战时各角色掷 `d100 + 体质 ADJ + LB`，从高到低行动。
- **回合**：每回合角色拥有 **移动 + 动作 + 附赠动作 + 反应**。
    - **动作**：攻击、施法、疾跑、闪避、协助等。
    - **附赠动作**：部分技艺/神通/机关术触发。
    - **反应**：借机攻击、部分护身神通。每名角色每轮最多使用1次反应；角色完成自己回合后恢复反应。

## 4. 攻击与防御（命中 vs AC）

> **攻击命中条件：`d100 + ADJ + LB + SKB（+ 神通加值×2，若为神通攻击）+ 境界压制修正 + 距离/状态修正 ≥ 目标 AC`**

- **近战武器**：d100 + 体质 ADJ + LB + 相关武技加值（武修/兵法等）。
- **法术攻击**：d100 + 灵元 ADJ + LB + 相关术法技艺加值（玄法/方术等）。
- **境界压制修正**：双方境界不同时计入（见四·2.4 的 S 表），同境界为 0。
- 目标 AC 为静态值；命中即进入伤害结算。

## 5. 伤害与灵膜

### 5.1 伤害

命中后结算伤害：

> **伤害 = 品阶伤害骰 + 相关 ADJ + LB + SKB（+ 神通加值×2，若为神通攻击）+ 境界压制修正 − 目标减伤**

- 近战/远程武器：伤害骰 + 体质 ADJ + LB + 相关武技加值；法术：伤害骰 + 灵元 ADJ + LB + 相关术法技艺加值。
- **重击**（掷出 96–100）：伤害骰翻倍（ADJ、LB、SKB 不翻倍）。
- **碾压**（对抗检定结果超出对方 20 点以上）：该次伤害 **+10**。
- **减伤**：护甲/铁布衫等提供固定减伤。
- **灵膜优先**：先扣灵膜，再扣 HP。

### 5.2 额外攻击

近战物理技艺在 **4 境（真阳）、6 境（先天）、9 境（玉真）** 各获得一次**额外攻击**：一个攻击动作可攻击 2 次 → 3 次 → 4 次。施法与远程技艺不获额外攻击。

### 5.3 灵膜（灵力护盾）

灵膜是修士的护盾，作为**临时HP值**：

- 受击时**先扣灵膜，再扣 HP**；MP=0 时灵膜消失。
- **恢复**：短休回满；战斗中可消耗 MP 回复灵膜（MP消耗量 = 灵膜回复量 = 灵元 ADJ）。

## 6. 状态与伤势

**伤势**：HP 降到一半以下为**受伤**；降到 1/4 以下为**重伤**；HP ≤ 0 为**濒死**。

- **受伤 / 重伤**：按下表承受检定修正，重伤者部分动作受限（GM 裁定）。
- **濒死**（HP ≤ 0）：倒地昏迷，**每个自己回合开始时**掷一次 d100（无调整）——**≥51** 累积 1 次成功，否则累积 1 次失败；**累计 2 次成功**则伤情稳定（昏迷，**1d4 小时后苏醒**，苏醒时 HP = 1）；**累计 3 次失败**则死亡。队友可花一个动作施救（检定≥DC 55），成功即视为累积 1 次成功。

常见状态（均可作为检定修正）：

| 状态        | 修正                               |
| --------- | -------------------------------- |
| 受伤（半血）    | −10                              |
| 重伤（1/4 血） | −20，部分动作受限                       |
| 中毒 / 灼烧   | 中毒：每回合1d6，强毒2d6；灼烧：每回合1d8；动作 −10 |
| 心魔侵扰      | 精神类检定 −15                        |
| 灵膜被破      | 本回合内后续伤害直接扣减 HP                  |

## 7. 休息与恢复

| 休息     | 时长                         | 效果                                                                               |
| ------ | -------------------------- | -------------------------------------------------------------------------------- |
| **短休** | 静修一炷香（约 15 分钟），**每日限 2 次** | ① **灵膜回满**（灵力护盾自循环）；② MP + 灵元 ADJ×2（MP不超过最大值）；③ 可自行包扎一次：HP + 体质 ADJ×2（每次短休限 1 次） |
| **长休** | 一夜安寝，每日 1 次                | **HP + 上限 × 50%**（不满部分靠包扎、治疗技艺或长期调养补足，见六·4）；MP / 灵膜**全满**；清除非永久性劣势与短期不良状态        |

> **长休不回满 HP**：肉体重伤需要时间调养——一夜睡醒就满血会让治疗资源、丹药、医愈技艺全部失去意义，也让"带伤赶路"的冒险张力消失。

- **战斗中**：花动作以 MP 回复灵膜；治疗类技艺（方术·医愈等）按技艺描述恢复 HP。
- **永久损伤**（灵桥断裂的属性 −5、献祭支付的寿命等）不因休息恢复，须按对应代价规则处理。

## 8. 物品（简述）

一些特别的物品可以永久性的提升角色的属性上限，但是并不能立刻就让你获得提升，要求充分吸收药效。部分药剂可以短暂的提升你的属性值，但这些药剂必然会短暂或永久的给你留下一定的后遗症，请谨慎使用。

- **治疗、耐受与丹毒**：当一个生物受伤时，他可以选择灵力或是药剂进行治疗，然而治愈类玄术和药剂的使用，都会产生相应的耐受性，尤其是多次连续使用将会难以获得完全的效果，有些药剂还会在身体遗留丹毒，因此肉体的损伤仍然需要依靠修养等方式进行治疗。而各类的治疗、强化药剂，甚至毒药也有类似的反应。通常来说，高级药剂将会覆盖低级药剂的效果，同时也将大量提升耐受性。

## 9. 战斗示例（简述）

陈默（启灵 1 级，玄法：灵元 10 → ADJ +0，LB +5，玄法真解 3 级 SKB +15，未用神通）以「引火术」攻击一名巡捕（凡人：体质 10 → ADJ +0，LB +0，无防御技艺，AC = 50+0+0 = 50，HP = 10×2 = 20，无灵膜）。

- **命中**：陈默攻击加值 = 0+5+15 = **+20**。掷 d100 得 48 → 48+20 = **68 ≥ 50**，命中。
- **伤害**：引火术为凡铁品阶（1d6）→ `1d6 + 0 + 5 + 15` = 1d6+20。掷 4 → **24**。巡捕无灵膜，直接扣 HP：20 − 24 ≤ 0，巡捕倒地。
- 若陈默掷出 96–100，则重击：伤害骰翻倍为 2d6+20；若掷出 01–05，则必然失手。
- 若陈默使用了神通（如 Lv1 攻击神通，神通加值 +5）：命中与伤害再 **+5×2 = +10**——这就是神通的"飞跃"。

## 10. 敌人构建

敌人与玩家**共用同一套判定机制**（ADJ/LB/SKB/DC/AC/伤害），但不走角色创建流程。GM 按**境界 + 模板 + 战场定位**三步直接查表生成。

### 10.1 第一步：定境界

### 10.3 第三步：战场定位（属性倾斜）

同一模板的敌人按战场定位倾斜属性：先按模板定出**主属性值**，再以此为基准——**主属性 100%、次属性 50%、第三项 25%**（向下取整）。各派生值分别用对应属性计算。

| 定位           | 主属性 | 次属性 | 战术特征         | 调整                               |
| ------------ | --- | --- | ------------ | -------------------------------- |
| **突进**（近战输出） | 体质  | 灵元  | 贴身缠斗、攻击次数多   | 标准模板                             |
| **炮台**（法术输出） | 灵元  | 魂魄  | 远程高品阶法术、灵膜厚  | 伤害骰升一品，HP×0.8；命中/伤害用灵元 ADJ       |
| **控制**（术法辅助） | 魂魄  | 灵元  | 减益、束缚、驱散     | 攻击加值 −10，控制类法术命中用魂魄 ADJ、控制检定 +10 |
| **护卫**（肉盾）   | 体质  | 魂魄  | 高 HP、减伤、保护友方 | HP×1.2，伤害 −20%，减伤 +5             |

> 例：生成一名**玄灵·精英·炮台**：主属性灵元 = 70×0.75 = 52，魂魄 26、体质 13；HP =（13×2 + 12×0.75）×0.8 ≈ 28，取整为25；灵膜 = 52；攻击加值 = ADJ(52)+15+15 = +38（法术）；伤害骰升一品为 2d8（天宝）。

### 10.4 头目及以上的额外行动机制

玩家小队有 4 个行动轮，单个敌人只有 1 个——额外行动是头目战不至于"被围殴致死"的平衡器：

- **头目（2 动作）**：每回合拥有 **2 个动作**（可攻击、施法、移动各一组合），反应仍为 1。
- **BOSS（2 动作 + 1 反应）**：另获**觉醒阶段**——HP 首次降至 50% 时触发：获得一项新能力（神通觉醒 / 攻击 +10 / 召唤援军，GM 定），并重置灵膜。
- **传说（3 动作 + 1 反应）**：另获——
    - **传说抗力**：每场战斗 3 次，将一次失败的检定改为成功（不接受大失败）；
    - **领域**：以自身为中心的场域效果（如卞梁王「七煞镇魂阵」：域内敌方每回合开始魂魄 DC 80，失败 −10）；
    - **觉醒阶段**同 BOSS。

> **配比建议**：对 4 人小队——同境界遭遇 = 精英×1 + 杂兵×3；头目战 = 头目×1 + 杂兵×4；BOSS 战 = BOSS×1（觉醒兜底）或 BOSS×1 + 精英×2。
