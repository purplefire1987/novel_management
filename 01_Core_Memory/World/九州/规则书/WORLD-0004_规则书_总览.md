## 卷首 · 本规则书的诞生

《九州规则书》是以《九州》世界观为基础的 TRPG 跑团规则。本规则书主要完成以下事项：

1. **统一设定层叙述与结算层数值**：境界=属性上限，技艺=技能池，道途=成长方向；
2. **建立角色创建流程**：从属性分配到技能选择，一步步生成一张可用的角色卡；
3. **建立统一的行动裁决机制**：用骰子贯穿所有检定与对抗；
4. **冒险与战斗的说明**：包括行动系统、战斗系统、神通系统、气运系统
