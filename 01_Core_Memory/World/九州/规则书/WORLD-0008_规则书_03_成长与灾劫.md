# 九州·成长与灾劫

> 来源：`九州TRPG规则书.md` ｜区间「# 三· 成长系统」→「# 四· 战斗系统」｜录入批次 `LORE-20261103-213615`｜原文照录，未改写、未补写。

## 一句话定位

升级给属性点与技艺点；突破境界要历劫，代价体系（灾劫）是「变强必须付出」的结算出口。

## 1. 经验值 / 技艺点 / 神通点

- **经验值（EXP）**：经验获得的方式多种多样，方士们可以通过炼丹、打坐、探索自然中的奥秘，学士们修身、齐家、治国、平天下等等。在TRPG中，主要依靠修炼获得、完成任务获得、战斗之后由 GM 发放，累积提升**等级**。
- **升级阈值**：升到下一级所需 EXP = **当前等级 × 100**（如 24→25 级需 2400 EXP）。境界内累计示例：启灵（1→10）共约 4500，玄灵（21→40）共约 6 万。
- **技艺点**：升级获得，用于提升技艺等级。每升 1 级 +1 点，用于提升技艺等级（GM可视情况调整）。
- **神通点**：稀缺资源，通过阅览古卷/碑文/命运石板或完成特殊事件获得，用于**获取/升级神通**。
- **里程碑制（剧情团推荐）**：不用经验表，每个重大剧情节点升 1 级（一卷约 2–4 级）；**抵达境界上限后须完成对应灾劫剧情方可突破**，经验不自动换境界。

## 2. 属性成长（ASI）与境界突破

- **属性成长（升级自由点制）**：主要靠**升级+境界突破**；**每升 1 级，获得 +1 自由属性点**，由玩家自行分配至体质 / 魂魄 / 灵元任意一项。
- **境界突破**：境界突破须历**灾劫，突破大境界成功时，额外 +3 自由属性点**（突破奖励，仅此一项，不与其他突破奖励叠加），失败则实力停滞或**天人五衰**。
- **属性上限**：随境界提升。再叠加修炼法门、特殊物品。**单项属性不可超当前境界上限**，达到上限的属性须等突破后方可继续加点；若已顶满，升级获得的属性点可转而投入"一项技艺"（1 属性点 = 1 技艺点）。
    - 总量对照：初始 30 + 174 次升级 ×1 + 8 次突破 ×3 ≈ **228 点**（玉真期满），曲线为"同境界平滑增长 + 突破跳涨"（突破时上限抬升 +20~25 且额外 +3 点）。
- **顿悟**：修士有可能陷入顿悟的特殊状态，在该状态下，可消耗气运点立即提升功法等级或是完成术法学习，在突破大境界时，功德点可以在突破时提升奖励。

## 3. 代价体系：灾劫

在修者想要越过某些特定境界时，他将面临灾劫。气运点数可以有效降低劫数的难度。

- **渡劫** = 一次突破检定（公式：`d100 + 相关属性 ADJ + LB + 相关技艺加值 + 神通加值×2 + 情境修正 ≥ DC`），**DC = B（当前境界）+ 95**。（GM可视情况降低玩家的渡劫难度）
    - **降低手段（可叠加）**：① 消耗 1 气运点，渡劫检定 **+20**；② 防御型神通可计入（**神通加值×2**，+10~+40，通明境后可用）；③ 丹药、护法大阵、吉地吉时等情境修正 **+5~+20**（GM 定）。
    - **参考通过率**（峰值满配、技艺 3 级的渡劫者）：裸渡 ~6%；+气运 ~26%；+气运+丹药护法（+15）~41%；通明后另持防御神通（Lv2，+20）可达 ~61%，这正是高境界修士稀缺的机制解释。
- **失败分级**：普通失败 → **停滞**（境界保留，灵能大损，须休养一旬并重新积累后方可再渡）；**大失败（01–05）** → **天人五衰**，最多跌两个境界。
- **火劫**：进阶第4境的劫数。（寻找并引动三昧之火，并用灵能护卫自身，使得体内成丹。）
- **风劫**：进阶第6境的劫数。（在裂风之地，锤炼自身，感悟天地，渡过难关。）
- **雷劫**：进阶第8境的劫数。（在生死之境，魂、体任一崩坏之际，寻求生机）
- **寂灭劫**：长期停留在第9境面临的劫数。（DC 由 GM 定，建议 95–105）。
- **天人五衰**：当超凡生命面临长期的境界停滞或某些情况时，就会出现天人五衰，首先是气运之衰，他的运气逐渐变差，在掷骰时会取较小值，大规模动用灵力时高概率遭遇天谴；其次是属性之衰，每过数年，他的属性值降低10%；再次是灵力之衰，他的回灵效能降低，灵力储存量逐年降低；四是神魂之衰，面对精神类术法时，抗性降低；最后是心性之衰，修炼效率降低，遭遇心魔的可能性大增。除非突破当前境界，否则无法避免该情况。所有通过偷取/夺取/延缓寿命等方式的生命都将面临这个问题。
- **心魔**：心魔在每个修炼境界都有一定概率阶段出现。心魔来袭 = **魂魄检定 DC 55 + 境界阶×5**，失败则陷入一段时间 DEBUFF（修炼/精神检定劣势）。功德点可以降低心魔出现概率、降低该 DC，或抵扣一次失败（若不使用功德点抵扣，则进入心魔战斗）。

### 附录 · 代价表

变强必有成本，GM 在以下情境触发代价检定：

| **代价**          | **触发**        | **机制落点**                                |
| --------------- | ------------- | --------------------------------------- |
| **守恒灵锁**        | 灵能需求超结构上限     | 超限施法检定 −10，且每超一级灵膜 −10                  |
| **灵桥断裂**        | 需求超灵元/魂魄容量且失衡 | 灵桥断，向上之路堵死；裂痕数 = 能级差²，每裂痕**永久 −5** 相关属性 |
| **天人五衰**        | 境界停滞/偷取寿命     | 五重衰败（气运/属性/灵力/神魂/心性）                    |
| **心魔**          | 执念过重          | 魂魄检定（DC 见上），失败陷入 DEBUFF（功德点可抵扣）         |
| **献祭反噬**        | 巫术/献祭道途/超阶玄法  | 施术者支付财富/寿命/诅咒；越阶杀人代价极高                  |
| **灵能虹吸 / 灵能风暴** | 超阶玄法          | 区域内，所有施法鉴定 -10                          |
