## 1. 神通系统

当一个通明境界的修者在长期的冒险过程中不断进步，天赋和锻炼相结合逐渐开花结果，最终他成功开悟，在通明境开悟或跨入先天境时会获得一个天赋神通，这是一种个体的浓缩。一项神通将会为修者的属性/能力带来飞跃性的提升，在攻防两端都拥有巨大的影响，甚至赋予他一项全新的战斗方式（在每一种技艺之上都可以添加该效果）。修者的神通分为主动能力和被动能力（可开关）。通常来讲神通并没有高下之分，也无强弱之别，但不同神通在不同场景中的战斗价值不同，而同一神通升级后会显著增强。

### 1.1 神通获取

- **获取时机**：**通明境**开悟获第一项神通；**先天境**必获一个天赋神通。
- **神通无必然命中**（仍要掷骰），使用神通时计入**神通加值 ×2**。
- **仙缘**（神通奇缘）：这是一段历史上的奇特经历，也是一段独特的体验，它将你拉进某个人的一生，如果你能完成他的使命/弥补他的遗憾，你将能获取相应的神通或是特异性称号。同时禁忌的知识、独特的际遇、长久的锤炼带来了个人的升华之语——【封号】。GM 通常会在一场华丽而且盛大的冒险之后，为每位幸存者们提供一定数量的神通点，可供试炼的仙缘。

| **要素**     | **说明**                                                                              |
| ---------- | ----------------------------------------------------------------------------------- |
| **神通点**    | 获得神通/升级神通的唯一资源。通过阅览特殊知识（古卷、碑文、命运石板）或完成特殊剧情事件/遗迹挑战获得。                                |
| **神通负担限制** | 每位修者最多可自然承载 **3 个神通**，超出者必须突破自身境界（如跨入先天），否则必然遭遇**反噬或神识紊乱**。                         |
| **成长值机制**  | 每项神通都有"成长槽"，使用/研究/特殊反馈积累成长值，满值后解锁升级资格。由 GM 或叙事控制进度。                                 |
| **升级限制**   | 升级需神通点、足够成长值，并需进入神通契合状态（与自身灵魂、技艺体系和谐共鸣）。                                            |
| **神通获取成本** | 第 1 个神通 1 点、第 2 个 2 点、第 3 个 4 点、之后每 +1，消耗点数翻倍（8/16/32…）。若未破境，则陷入神识错乱/灵能溢出/灵元崩裂等反噬事件 |

### 1.2 神通种类

| **种类** | **形态**            |
| ------ | ----------------- |
| 光环     | 持续笼罩自身或区域的被动场     |
| 响应     | 特定条件触发的一次性 / 应激能力 |
| 变化     | 改变自身形态、体质或属性偏向    |
| 仪式     | 需场地 / 仪型 / 仪材配合发动 |
| 特质     | 恒定生效、无需消耗的被动能力    |
| 场域     | 改写一定范围内规则的领域能力    |

- 另可按**元素**（金木水火土）、**触发方式**（即时 / 恒定）、**预言术**等维度划分。
- 预言术的本质是观察世界运转、总结规律，而从某种微小的事件发现预兆，由此演化出了不同类型的推演术与预言术，正确与确定的预言通常是唬人的，而可能性则是更核心的能力。

### **1.3 升级与进阶机制说明**

#### **1.3.1 神通成长与升级**

一项神通可以通过以下方式成长：

- **神通领域扩展**：修炼者能够拓展自己的神通到更广泛的范围。
- **神通效果强化**：神通等级的上升能够令其已有的神通效果更为强大。比如，治愈神通的治疗效果更为迅速、彻底，攻击神通的威力更为惊人。

每个神通初始为 **Lv1**，最多可升级至 **Lv3**，之后进入进阶阶段。

| **等级** | **神通加值** | **成长描述**     | **神通点升级消耗** | **典型变化**          |
| ------ | -------- | ------------ | ----------- | ----------------- |
| Lv1    | \+5      | 初次获得，解锁神通成长槽 | 见“神通获取成本”   | 神通初现              |
| Lv2    | \+10     | 效果提升，代价下降    | 2 神通点       | 时间延长、命中提升、使用方式多样化 |
| Lv3    | \+15     | 神通极限，人技合一    | 3 神通点       | 极限变化+自我掌控强化       |
| LvX    | \+20     | 需进化/融合       | 特殊方式        | 演化全新结构或神通         |

#### **1.3.2 神通进阶**

当修者经过不断的学习和使用，神通将会达到一个上限。在达到洞玄境界后，神通可以通过飞升等类似的手段突破限制，获得进阶（你的经历与知识、对整个世界的认知影响了你最终获得的神通）。

#### 进阶之路

- **融合**：修者可将不同的神通进行融合，创造出新的、更强大的神通。这需要极高修为和对神通的深刻理解。
- **进化**：在长久的修习中，修炼者有望突破原有的神通境界，达到更高层次，使得其神通能力更为深奥玄妙，需积累四要素灵纹——**怪**（怪异之力）、**力**（文明之力）、**乱**（混乱之力）、**神**（神明之力），可能会超越原有形式，形成全新的威能。比如，能够掌控更为神秘的法则，操纵更为庞大的天地力量。 
- **连接**： 修者能够通过神通与神明、法则、宇宙的更高层面建立联系。这种联系可能获取启示或能量，也可能引发神秘的神通变化。

### **1.4 神通融合 & 进化范例**

**【神通融合】范例：**

- **条件**：两个兼容神通 + 经历“破界试炼” + 神通圆满 + 百蟒
- **例子**：【三头六臂】+【蟒骨化生】→【无相·百臂蛇魔】
        - 效果：幻肢操控、主动分裂出“灵体附臂”，使用更多武器同时作战
        - 限制：持续时间10分钟，巨量灵能消耗

**【神通进化】范例：**

- **条件**：达到第8境及以上 + “怪力乱神” + 神通圆满
- **例子**：【附火】→【焚界·赤痕】
        - 效果：火焰附带“附着”效果，烧灼残影停滞于空间中，任何靠近者都会中招
        - 新代价：每使用一次烧灼灵根，需闭关十日恢复

### **1.5 神通使用的消耗与代价总览**

神通作为一种强力技能，必定牵涉到**使用代价**，每次发动神通时，按以下因子投掷反噬概率**（可由GM决定），**所有当次适用的触发项直接相加，最高95%。：

- **超负荷使用**（灵能不足仍强行发动）=25%
- **通明境界使用神通**=10%
- **神通持有数超标**（神通未扩容即使用）=20%
- **使用失败/中断时**（被打断或目标强制中止）=15%
- **与特定领域冲突**（禁咒类/因果类神通在特殊区域使用）=10%
- **重伤未恢复**=20%

## 2.仪式系统

一种特有的沟通灵能网络的方式，通过一系列的符号、姿势、动作、特殊物件、语言等方式在特定的时间和场所进行扩展式的扰动和调用"灵能"。其中最强大的，毫无疑问是"创造类仪式"与"飞升仪式"。

- **仪式构成**：场地、仪型、仪材、仪演。
    - **场地**：这个场地必须是一个**统一属性的灵能场地**，若是当下没有这个场地，可以通过净化与重建围出这样一个场地。在大多数的仪式玄法，通常可以使用蜡烛、宝珠、薰香等物品配合净化咒语，然后再用灵晶磨成的粉末围成场地，最佳的仪式场地则是法坛、祭坛或类似的地方。
    - **仪型**：通常有很多平面图形可以更简单和方便地调动灵能和定位坐标，例如圆形、方形、五芒星形、星形图等，这些被统称为仪型，有一些高级仪式则需要形成立体图形。请注意，仪型的绘制顺序非常重要，例如顺时针的圆形与逆时针的圆形所适用的仪式并不相同。
    - **仪材**：通常的仪式材料仅仅只需要投入足量的灵力，召唤类的仪式则需要更多的准备——对应生物的灵能血肉或是其他灵能物品。
    - **仪演**：一些大型仪式必须使用对应的步伐或动作、语言来逐步理顺场地内的灵能，这些被统一称为仪演，例如长生会的大醮就必然会使用复杂的禹步与文策来进行仪演。
    - **其他**：在各大教派中均有关于具体仪式的内容——仁理学派主要是礼仪（礼仪是学士们面对未知而保护自己的仪式），长生隐修会则是醮仪（其中规模最大的是罗天大醮），轮回教派是水陆法坛，兵马略主要是兵阵之式（兵家阵法），公府为刑名法审，长歌行为盟誓。
- **失败**：仪式失败造成严重反噬，大能亦可能死于仪式，请谨慎使用。
- **飞升仪式**：造化境瓶颈后游历积累，为了谋求进一步的提升，这些人们会去依照灵感的指引去进行游历，当他们需要把这些游历转化为冲破关卡的积累时，飞升仪式成为最重要的途径，成功举行飞升仪式后将达到传说级，修得真灵。每次飞升仪式都会创造一次心内幻境的冒险，突破该冒险将成功飞升。飞升时会出现天地异象，飞升仪式不在于规模的大小。
- **创造仪式**：无法创造魂魄，只能以肉体与已有灵魂创造新生命。
- **仪式检定**：使用统一公式；仪式的 DC、耗时、材料和特殊修正由仪式描述确定。

## 3.气运系统

时来天地皆同力，运去英雄不自由！气运系统包含天意、气运和功德三项。

- **天意值**（1–6）：决定冒险规模，为GM提供冒险强度预算。在九州之中，一段冒险会出现什么等级的boss，能获得什么级别的宝藏，以天意值决定。在一场冒险之中，天意值可能会随着时间变化。天意值与气运点的获取有正相关的关系。
- **气运点**：气运点数有几种获取方式，第一种是人物初始就有的，第二种是角色在经历重大胜利或是灾难性的不幸时获得了特殊奖励。第三种是根据平常获取的功德点进行兑换。
    - **初始点数**：初始 1 点，可受到命格可调。
    - **获得方式**：经重大胜利/克服重大失败/剧情节点/功德兑换获得。
    - **特殊情况**：若角色体验到个人的重大挫折或是毁灭性事件时，他将首先获得一些临时性的气运减值，若能成功渡过则增加一个时间段内的加值BUFF，若他最终未能成功对抗心魔，他将获得永久性的气运减值。若角色此时走向邪恶途径，他也有可能获得气运点，视情况而定。
    - 气运不是单纯的幸运值，而是“被命运关注的程度”；气运越高，遭遇重要事件的概率越高，但事件结果整体更有利。
- **功德点**：行善/破邪/教化积累，兑换气运/物品/技能。角色在日常生活中可以积累，在特定事件中，这些功德点可以大量获得。在突破大境界时，功德点数高可以在突破时获得额外奖励。

| **获取方式**      |                                                                              |
| （1）重大胜利       | 角色会在其克服了特定的核心障碍后获得气运点，这意味着他们完成了一项特殊的特殊考验，比如击败强敌、救出真爱、攻克一些棘手的谜团或难题，帮助了某些大人物等。 |
| （2）重大失败后的心魔克服 | 当他们度过伤痛、克服障碍时，他们重新振作，直面挑战，将获得气运点。比如，爱人或挚友之死、失去重要工作、屈服于现实（有害的角色缺陷），被诬陷犯下罪行等。  |
| 剧情节点事件        | 某些剧情会直接临时提升或降低气运                                                             |
| 功德点兑换         | **100 功德 = 1 气运**                                                            |
| **消耗方式**      | 关键节点或通过主动选择触发气运能力                                                            |
| **五大作用**      |                                                                              |
| （1）触发奇遇       | 有助于玩家进入隐藏副本、获得未知修法、邂逅重要人物等                                                   |
| （2）命运决断       | 可重新选择一次，意味着玩家可以改变决策，避免潜在风险（如避免身死、选对道路）                                       |
| （3）强制突破       | 修炼中若差一点即失败，可强行消耗1~3点气运解除；若处于**顿悟状态**，可消耗气运点立即提升功法等级或完成术法学习                   |
| （4）奇迹之手       | 临死或绝境中消耗点数强行启动“事件逆转”                                                         |
| （5）天命赐福       | 短时间内获得“幸运”状态，消耗点数后，玩家有机会进入隐藏势力或者洞天福地                                         |
| **负值惩罚**      | 若气运跌至负值，角色常陷入意外、死亡率上升、敌视值提升、奇遇变奇灾，进入“命途多舛”状态                                 |

## 4.扩展：天命真灵系统（非核心规则）

**定位**：以下为九重之上「传说级」（天命/太虚/无极/混元）的扩展内容，供 GM 在高阶战役或结局篇使用；**不是常规可玩境界的规则**，低中阶跑团无需阅读。

当你抵达灵能平原的终点，站上双漩之塔的顶端，点燃灵能之火，你将会遇见一项新的阻碍——宿命之障。宿命，是一个角色获得天命真灵所必经的一个极具危险的冒险，通过一系列的潜修、试炼，你终于冲破了这道障碍，解锁了全新的形态——天命真灵！

天命真灵可直接通过念识调用灵能网络中的灵能，又能制造自己独享的灵能网络，制定专属的灵能运转规则。天命真灵能够打破技艺的固有使用条件，甚至无中生有。可以获得天命的传承，创造强大的秘术；亦可完全改变命格，或是与天签订盟约。

天命真灵是贯通了人与天地的桥梁，在这个阶段会提供很多独一无二的奖励。不同的天命真灵将会获得完全不同的特性。

真灵不灭！即使死亡，天命真灵也不会被消灭，而是可以通过脱胎换骨等手段重获新生。

**宿命之障**：独面晋升宿命之障的关卡挑战，在该挑战中集齐五种属性的封号，使用特殊道具可以突破。气运点数可以降低宿命副本的难度。

    - **宿命之谜**：玩家首先进入由宿命编织的复杂迷宫，需要解谜、操控机关才能顺利通过。迷宫中隐匿着宿命的种种线索，需要玩家的智慧和洞察力。
    - **命运试炼**： 在副本中，玩家将面对一系列命运试炼，如时间压力、资源匮乏、无尽怪物潮袭来等。每个试炼都要求玩家有高效的应对策略，否则将付出沉重的代价。
    - **宿命守护者**：玩家将遭遇强大的宿命守护者，每个守护者代表一种命运的力量。玩家需要制定出色的战术来战胜这些守护者。

目前已知的升阶：

**天尊**：（1）一气化三清，你将获得三倍的攻击范围，可同时使用三个不同的减品玄术；（2）道可道，你每个玄术都将获得最强效果；（3）众妙之门，你被允许重构法术。（4）天尊洞府，“天地不仁，以万物为刍狗”，你将获得崇绝之领“天尊洞府”，此区域的所有敌方将对抗你的检定，无法通过则被剥夺灵能。
