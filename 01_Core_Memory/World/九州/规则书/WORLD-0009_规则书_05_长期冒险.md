# 九州·长期冒险

> 来源：`九州TRPG规则书.md` ｜区间「# 五 · 长期冒险系统」→「# 六· 附属系统」｜录入批次 `LORE-20261103-223926`｜原文照录，未改写、未补写。

## 一句话定位

时间推进、旅行、补给、休整日与事件时钟（天意值驱动）——长篇连载的节奏控制工具。

本章解决"一段旅程"——角色在两次战斗之间如何赶路、吃饭、修炼、养伤，世界如何随时间推进。GM 可按战役节奏自由取舍五个模块。

## 1. 时间推进

- **基本单位**：日。10日一旬、3旬一月、3月一季、4季一年（帝国历，见世界观文档）。
- **节奏建议**：冒险日（遭遇/探索）与休整日（长期行动）交替；连续冒险超过 3 日，GM 应安排或玩家主动申请休整，否则带伤/缺资源进入下一场遭遇。

## 2. 旅行

| 方式       | 每日里程  | 备注                      |
| -------- | ----- | ----------------------- |
| 步行       | 30 里  | 平原官道；山地/沼泽/冰原减半         |
| 骑马/驮兽    | 60 里  | 需驿站或自备草料                |
| 马车/商队    | 45 里  | 可载重货与伤员                 |
| 内河船      | 80 里  | 顺流 +50%，逆流 −30%         |
| 灵械载具     | 300 里 | 需灵晶燃料，机关术门可维护           |
| 飞行（先天以上） | 500 里 | 灵能外放级修士，每日消耗 MP 上限 ×40% |

- **天气**：暴雨/暴雪/沙暴 → 里程减半且当日遭遇检定**劣势**；台风/沙暴中心 → 无法行进。
- **露宿**：野外露宿视为长休但 HP 恢复减半（25%）；扎营需守夜轮值，守夜者次日 MP 恢复减半。
- **疆域尺度**：跨城旅行以**旬**计、跨州以**月**计——旅行本身就是冒险段落。旅行时间 = 路程 ÷ 每日里程。路程由地图库提供距离。

## 3. 补给

货币以**纸币**为主（铜钱/银票并存，见世界观文档）。参考物价（可按州府丰俭 ±50%）：

| 项目             | 价格    |
| -------------- | ----- |
| 客栈一宿（人）        | 20 文  |
| 干粮一日份          | 5 文   |
| 普通伤药（包扎 +5 HP） | 50 文  |
| 灵力药剂（MP +20）   | 2 两银  |
| 凡铁武器           | 5 两银  |
| 解毒/清丹毒药剂       | 5 两银  |
| 灵晶（灵舟一日燃料）     | 10 两银 |
| 马匹（匹）          | 30 两银 |

- **断补给**：无干粮每日 1 餐 → 当日全检定 −5，累计 3 日再 −5（最多 −15）。
- **药品耐受**：同种药剂连续使用见耐受规则，丹毒须调养清除（见下）。

## 4. 长期行动（休整日）

每个休整日，每名角色从下列行动中选择 **1 项**：

| 行动        | 效果                                               |
| --------- | ------------------------------------------------ |
| **修炼**    | 获得 EXP = 等级 × 20（日）                              |
| **训练**    | 一项技艺累积训练进度：1 日 = 0.1 技艺点等效（不可超等级上限）              |
| **制作**    | 创生法/机关术：按物品品级耗时（凡铁 1 日…天宝 1 季）                   |
| **调养**    | 调养2日：HP恢复至满值，并清除1级治疗耐受或1点丹毒；重伤者必须先完成一次调养，才能进行训练。 |
| **行善**    | 参与地方事务：获得功德点（GM 按事迹 1–5 点）                       |
| **交际/打探** | 获取情报、建立人脉：魂魄检定 DC 按当地阶层定（55–80）                  |

> **日行动**：角色把一天作为休整单位使用。

> **旬行动**：角色连续10日执行同一长期行动，获得10倍收益，同时跳过每日相关结算。

## 5. 事件时钟（天意值驱动）

世界不等玩家。GM 以**天意值**为烈度推进后台时钟：

| 周期     | 时钟动作                                                                  |
| ------ | --------------------------------------------------------------------- |
| **每日** | 旅行/露宿时掷一次遭遇检定：d100 ≤ 气运值 × 3 → 触发遭遇（敌人/商队/异象）                         |
| **每旬** | 掷势力动态：d100 ≤ 天意值 × 10 → 区域内某势力采取一步行动（扩张/结盟/缉拿/开价），GM 记录并让它在后续剧情中"长出来" |
| **每月** | 推进大事件时钟一格：战争、瘟疫、股灾、教派阴谋等长线危机（刻度 6 格），走满即爆发——玩家干预可改向                   |

> **设计意图**：事件时钟保证"一段冒险"有压力与方向——资源会消耗、伤势会积累、世界会变化，玩家的每个休整决策都有代价。

> **遭遇建议概率**：奇遇 10%；敌人 40%；中立NPC 15%；商队 15%；环境事件 20%
