# 九州·境界表

> 来源：`九州-世界观资产.xlsx` · 工作表「境界表」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如原文与规则书表述冲突，以规则书为准。

## 用途

九重境界的等级区间、单属性上限、成长值与晋升难点——判定人物强度的唯一标尺。

## 启灵

- **等级下限**：1
- **等级上限**：10
- **固定属性最低成长值**：1
- **固定属性成长最高值**：5
- **自由属性成长值**：2
- **晋升难点**：多数凡人无法稳定感应和吸收游离的灵能
- **战力对标**：巡捕、保镖、普通士兵
- **境界特征**：通感灵根，激活自身灵气的活跃
- **美术表现**：眼中灵光初开，眸中可现青芒/体表隐现若有若无的蓝白灵尘漂浮。
- **文本说明**：初入修行的人。初次感知灵能，打通灵脉，以灵气蓄积和循环自身灵力为主。此阶段灵能修为较低，主要提高肉身基础承载力。

## 培元

- **等级下限**：11
- **等级上限**：20
- **固定属性最低成长值**：2
- **固定属性成长最高值**：10
- **自由属性成长值**：3
- **晋升难点**：打通灵力循环、稳固灵能运转，常因体质或精神散乱失败
- **战力对标**：捕头、镖师、地方官护卫、精英士兵、绣衣郎
- **境界特征**：聚灵培元，不管是内练采灵，还是还是打熬身体，都是为了最终内外相合，打磨小周天循环
- **美术表现**：灵气循环初现，双手掌纹亮起淡金色光纹/掌心出现微弱的光团/拳脚挥舞间带残影/呼吸时有气息逸散
- **文本说明**：开始构建灵能结构，将吸收的灵能凝结为灵元。学习采灵法/修炼法，能够修得灵气循环，并正常使用，激活太玄盘后可使用固有法术。
- **关联：角色库**：老贺

## 玄灵

- **等级下限**：21
- **等级上限**：40
- **固定属性最低成长值**：3
- **固定属性成长最高值**：15
- **自由属性成长值**：4
- **晋升难点**：构建稳定的“灵能循环回路”，大多因心志不坚、逻辑结构不全而断裂
- **战力对标**：小型组织精英、主战精锐、地方武官、文士弟子
- **境界特征**：灵桥构筑，玄窍成（节点），阴生，灵能结构稳定，明确自身的气性，获得技艺精通
- **美术表现**：在节点处或使用时有灵光浮现，灵气使用时可见薄雾缭绕，轻功使用时在脚上浮现灵气/灵气在体表形成淡薄护壁
- **文本说明**：掌握了灵力的玄妙，能够同时激活多个固有法术，多数能力者的极限。灵元稳固，可运转玄法。灵桥更加稳固。灵能承载力接近饱和，突破时需要历劫。
- **关联：角色库**：陈默,石季崇,黎江,安凌,安素妍

## 真阳

- **等级下限**：41
- **等级上限**：60
- **固定属性最低成长值**：10
- **固定属性成长最高值**：20
- **自由属性成长值**：5
- **晋升难点**：火劫，寻找并引动三昧之火（比如引火丹），并用灵能护卫自身，赋予灵能攻伐与驱动之力。灵能需从量变过渡为质变，失败者易陷“灵涌逆灌”反噬自身
- **战力对标**：丙等/真修/学者、力士、门派中坚、精英小队
- **境界特征**：灵元（架构雏形）成，阳生，燃烧灵种，技艺精通可以融合，大幅提高威力和针对性，灵能结构具备“单向抗压”能力。开始拥有术法“连续释放能力”
- **美术表现**：丹田位置出现红阳灵核，运转时可见灵气护体/微弱灵气流旋绕/血气冲霄
- **文本说明**：真修，敲开了修行的门扉，拥有玄妙之法（太玄盘接口调用能力升级，可自由搭配灵质石），获得气场、气机锁定和灵力外放（灵身/真印，可以用来威慑敌人、隐藏自身、加速）。灵能外放，灵力护体。
- **关联：角色库**：张香韬,林舒,项月溪

## 通明

- **等级下限**：61
- **等级上限**：80
- **固定属性最低成长值**：15
- **固定属性成长最高值**：30
- **自由属性成长值**：6
- **晋升难点**：意志受扰，易误入“心魔异象”
- **战力对标**：乙等、黄巾力士、王牌小队、中级军官、小型门派首领、邪魔
- **境界特征**：拓经脉生成灵脉，选择相适应的方向形成不同的辐射路径改善体质（架构）。拥有预警等超自然感应，灵场对世界产生“微观干涉”能力，灵元具备“自愈结构”
- **美术表现**：身周浮现虚影灵相，周身常有风动灵光，眸中可见星芒跃动，气机可引物动/灵气化作半透明流体在空中流转
- **文本说明**：帝国的精英阶层，一般资源堆积最高能到此境界，拥有多个战斗专精，能使用名品以上的器具，有些流派开发出了秘藏（身体的神通）。内外贯通，灵元结构趋于完整。灵能使用更为自由，但每次层级突破都对灵元结构和灵能平衡提出更高要求。超出常规层级后，可使用超阶玄法等秘术，然而需要以生命、魂魄等极大代价支撑，风险极高。
- **关联：角色库**：项磊,长桑公,孙福全,桃霄

## 先天

- **等级下限**：81
- **等级上限**：100
- **固定属性最低成长值**：20
- **固定属性成长最高值**：40
- **自由属性成长值**：8
- **晋升难点**：风劫：寻找并引动六气（比如引风丹，阴、阳、风、雨、晦、明）锤炼自身，感悟天地，渡过难关。
- **战力对标**：甲等/真人/悟者/高士/宗师、黄巾力士队、名将/封君、巨灵神、孽魔
- **境界特征**：窍穴积蓄灵质可形成防御场（云图），灵场结构高度有序化，拥有稳定灵海结构，可形成压倒性灵压区域，对万物有不同的理解，强化、细化核心技能，获得第一个神通，引发自然异象，形成“灵能干涉现象”
- **美术表现**：灵气凝结，体外生成护体光轮/身体后显现虚幻法相/气劲属性外放，地面会变为该角色属性的底色
- **文本说明**：部分法术能力转为神通（无须施法，动念施放），拥有了进一步前进的基础，太玄盘可以装配道理铜板进行使用，非肉体强化能力者仍然能被军用标准型号的汽铳击伤，获得法身。灵力与物质高度融合，具备自愈与重构能力。
- **关联：角色库**：项旒,岳荣,周景瑜,洛绮,关鹏飞

## 造化

- **等级下限**：101
- **等级上限**：125
- **固定属性最低成长值**：30
- **固定属性成长最高值**：60
- **自由属性成长值**：10
- **晋升难点**：天地反应、灵识反向牵引，稍不慎便“魂魄蒙尘”或招来“能级囚笼”的试探性共振
- **战力对标**：青云士/大宗师/真君、巨灵神军团（25台）、秽主
- **境界特征**：夺天地之造化，额外获得一个神通，有物体能力、灵体能力、魂体能力的分化选择
- **美术表现**：身体被光环环绕，显现虚影，背后浮现巨型异相，如怪物、轮、光晕、星象等，周边环境伴随灵气鼓荡。所有环境模型都会产生“水波纹”抖动
- **文本说明**：修者能够使用玄宝，属性获得全面提升精神与灵能结合，意识拥有了能量形态，可使用精神攻击，硬扛军用强击型号。能局部改写环境法则。
- **关联：角色库**：孙鑫源,李青莲

- **固定属性成长最高值**：80

- **美术表现**：周身范围形成“局部气候”
- **文本说明**：帝国的顶级战力，割据一方的霸主，神通可以组合释放，作为顶级修士，拥有区域禁法能力，低阶修者无法在他的区域内使用能力。近于神性生命。
- **关联：角色库**：裴冉

## 玉真

- **等级下限**：151
- **等级上限**：175
- **固定属性最低成长值**：50
- **固定属性成长最高值**：100
- **自由属性成长值**：60
- **晋升难点**：灵能释放量剧增，若调度不慎极易造成区域“灵能虹吸”甚至灵灾；战斗中需刻意压制
- **战力对标**：邪神、十二金人阵法/大仁/钜子/武神/巫皇/世尊/天师、古神、齐天大圣（超频形态）
- **境界特征**：三花聚顶、和合四象，了解宿命之障，吸收完整的魂、灵、体，虚灵成长完全，回归玄窍再孕育元真，“究竟微妙，洞达幽玄”
- **美术表现**：身体有虚化状态，使用时有强引力视觉特效，灵能环绕，线条或粒子呈“文字”或“符号”化
- **文本说明**：大神通者，小国杀手，多有帝国尊位，无消耗使用各类法术，法相接近实质，或掌握了某项圣人之遗，范围内压制所有低阶修者的灵能，可以正面硬抗奇观武器。完全升华，神性生命。
- **关联：角色库**：周之恒

- **等级上限**：200
- **固定属性最低成长值**：100
- **固定属性成长最高值**：150
- **自由属性成长值**：100
- **晋升难点**：心劫：所学所有法门逻辑将被世界意志测试：你所信的“法”是否存在自洽？你的存在能否经得起世界认知的锚定？
- **战力对标**：星空行者、外神、星神
- **境界特征**：真灵形态，挣脱了宿命束缚并掌握自身的天命，有天命之姿、权柄碎片，触摸到了道的边界，至少握有一项完整的权柄（概念性神通，生命跃迁）、最初和最终的生命形态，通过一场盛大的仪式（至少需要3个条件，分别对应肉、灵、魂），获得了完美个体、完善权柄和完整概念锚定
- **文本说明**：九州可承受的最强者
