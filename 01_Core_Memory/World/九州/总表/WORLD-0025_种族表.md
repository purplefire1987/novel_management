- **类别**：羽族属
- **简介**：灵性极高的肉食鸟类，以大鹏为尊
- **语言**：羽韵/凤歌
- **文字**：云纹
- **平均寿命**：200年
- **种族风俗**：当羽族人死亡时，他们的族人会为举行天葬，羽族人的鸟伴会带着他们的尸体飞到九天罡风之上，在罡风中一起化为灰烬。
