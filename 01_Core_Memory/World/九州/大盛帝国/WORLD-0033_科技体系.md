# 大盛帝国·科技体系（汽轮·灵能·印绶）

> 来源：`大盛帝国设定.md` ｜区间「**帝国的科技**」→「**政治**」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写、未补写。

## 一句话定位

三条技术线构成帝国的硬底：汽轮机（气动轮→汽炉→汽轮炉甲型）、灵能技术（灵晶与太玄盘）、印绶技术（官印压修者）。

---

汽轮机的发展历程及新时代：帝国历35年，九州第一台，被命名为“气动轮”的机器诞生了，随后不断有研究人员对汽轮机进行了改良（分离式冷凝器、汽炉外隔热层、连杆机关、节气阀、压力计、气动仪），第一代可量产的汽轮机“汽炉”于帝国历87年被研发，随后汽轮机开始在帝国各大行业掀起风暴，并带动了生产力的跳跃式大发展，由此整个帝国开始了巨大变革；帝国历95年，基于汽轮动力学理论的成熟（循环器，多级冲动式，水汽通过喷嘴成为高压气流后喷射到叶子上），汽轮机在大型化和小型化都取得了新的突破。

汽轮技术：基于汽轮动力学的成熟，帝国的工匠们利用算术十书作为工具，通过灵能技术的应用，汽轮机在小型化发展上获得了突破性进展，于通过灵流回路技术开发出了高压立方（镌刻有灵流回路，将水汽进行反复压缩的小型立方物），汽轮机的大型化则于同年开发出了超大型汽轮机“汽轮炉甲型”，后续更诞生了“共工”级的超级汽轮炉。武器方面则利用水汽驱动、推射炮弹等。

灵能技术：独立于汽轮机序列的技术系列，被誉为帝国的基石，灵能技术的发展比汽轮机的发展还要久远，只是多用于军备方面，灵能网络的建设和太玄盘的发展就是灵能技术的两颗最亮的明珠。目前，帝国的灵能技术并未获得新的开创性理论，近期的探索方向则是储灵石，用以解决对人使用负担过重的问题。灵能技术现在的核心是灵晶，灵晶一般以纯度进行分级，帝国的研究界尚未解决灵晶的形成、灵晶的人工制造、灵能的存储等问题。

印绶技术：这项技术是由法家学派中的势支提出的理论，并与仁理学派、行者学派一同研究出来的。无论任何人在完成印绶仪式后，依靠煌煌秩序之威（即礼与法的力量），可驱使官印对抗和威压修者（但只能在帝国政令通行的土地上），使下级官员从此有了自保的能力。乱世之中，人道崩灭，官印的力量迅速的削弱了。在帝国一统天下后，于四世时期重现这项技术，从而让修者们进一步在帝权下低头。
