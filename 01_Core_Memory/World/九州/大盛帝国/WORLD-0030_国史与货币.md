# 大盛帝国·国史与货币

> 来源：`大盛帝国设定.md` ｜区间「# 大盛帝国设定」→「**帝国军旅**」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写、未补写。

## 一句话定位

帝国起于第四纪元夏氏部落，一统九州后统一币制：铜子为日常通宝，银元、金珠为上币，另有铸币监发行的金券与银票。

---

**帝国的历史**

帝国崛起于第四纪元，前身是人族部落——夏氏。上古时代结束后，幸存者们开始划分势力范围，聚集领民，休养生息，一些获得了古代大妖们眷顾的势力被称作部落。在第四纪的中期，随着部落之间的逐渐壮大， 他们不可避免的开始了互相征伐、争夺大陆霸权的战争。在这个过程中，夏氏迅速的崛起了。

**帝国的经济**

货币：帝国在统一九州之前，各地的钱币形状不一，如刀币、环钱等，且只能在各自管辖范围内流通；帝国在统一九州之后，收天下之钱以重铸，结束了古代钱币形状各异、重量悬殊的杂乱状态。新的统一货币为圆形方孔的铜子（通宝），在长达数百年的发展之后，帝国又发行了银元和金珠作为交易货币（时间并不长），并厘定三种货币的币值——1金珠=100银元=100000铜子，金珠制造精美，初版为“龙金珠”，其后各朝各代又有其他版本。由于黄金和白银是帝国发展中的重要耗材之一，帝国为了维持金银稳定、保证交易的便利性，授命“铸币监”发行了纸质货币“金券”、“银票”，铜子作为日常使用单位仍然是通宝形制；金券最小额度为1两黄金，等值于1金珠，总共有1、5、10三种面值，由户部黄金作为“金券”的保障，金券由特殊纸张制造，纸张中隐含金线，纸面印有“上京盛世图”；银票最小额度为1两白银，纸张中隐含银丝，印有“始皇帝”的画像，象征着帝国开元，面值则有1、5、10、50、100共5种。因为帝国早已不再发行金珠了，金珠在坊间的价值要远高于金券，成为了权贵的收藏品，黑市上的一个“龙金珠”甚至能卖出数十上百金券的价格。事实上，普通人家或许一辈子都用不到金券来进行交易。帝国经济繁荣，斗米（10斤）10元，普通男性一天约消耗2斤米。九州对货物一般性的交易简称是“xx金，xx银，xx铜/文/钱”。

经济系统的特性：帝国当前的经济结构是金字塔结构，大部分的财富掌握在上层。在经济体系上，是正在不断重塑中的市场-贵族等经济体系的变革体。
