# 大盛帝国·语言·现状·文武之争

> 来源：`大盛帝国设定.md` ｜区间「**语言**」→「**对修士的管理**」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写、未补写。

## 一句话定位

夏语为官话，分雅言与方言；承平日久下暗流涌动——新旧势力、文武之争、蓬莱协定、旋转门与防御线。

---

在帝国统一天下之后，定都于中州，夏语成为人族的官方语言，由于偏远地区仍然有口音上的区别，于是有雅言和方言上的区分，但这种语言已无法直接调动原始灵力。

**现状**

帝国是九州最强盛的政权，承平日久，看似繁花似锦、烈火烹油，其实隐患不断——强大的修者们、隐藏在暗处的反叛势力（包括在统一过程中被消灭的部落和在社会浪潮中被淘汰的群体）、新兴的富豪阶层、边境的各族还有帝国内的权力斗争（中央与地方、中央与中央）。在帝国开始汽动革命后，经济重新开始了飞速的流动，商业主、工坊主登上了帝国的舞台，为了谋求更多的权力，他们成立隐秘的组织，并在暗中谋划着什么，目前可知的情报中，苍州、戎州的人民叛乱都有他们的影子，但是他们最终的谋划是什么，现在还无人可知。高层们在想办法缓解越来越大的贫富差距，而新贵与旧阀的斗争则日益剧烈，其中最重要的原因就是汽轮机的大力发展。强大力量的个体超越了智力、财富、家族等因素更加不受社会的约束。修者们漠视着普通人的生命，却又十分重视自己的生命；怪物在满足自我的欲望面前，却连性命都不顾，只有寥寥有数的几个才会懂的面对死亡的恐惧。在这个改革的时代，许多人依靠运气、手段、智慧、胆识，甚至只是投机取巧，于是短时间就一夜暴富，人民的物质生活愈加富裕，众多的底层人民似乎有了更多的机会去改善生活。然而事实上，更多的利益被掌握在大贵族和大商人手中，整个社会的形态已经不足以维持秩序的稳定，于是开始有了缓慢的变化——新旧势力的大战，一波又一波的动乱以致于皇廷的威信渐弱，帝国权力的争斗，思想的净化，资源垄断的对抗，这中间引发的各种各样形式的问题。

文武之争：在帝国早期，贵族是独立于官员的另一个系统，主要奖励军功卓越者，早期规定“唯斩获敌之首级方可论爵，非开疆拓土之功不可论公”；目前，帝国在政治上的考量，贵族的最底层增加了荣爵士和恩爵士的荣誉途径。帝国目前权力斗争日渐激烈，不论是贯彻执政理念或争夺权力，党争都已初现雏形。由于贵族多出于武事，官员出自政务大考主理政事，双方久已不和。

蓬莱协定：各族顶级强者在蓬莱定下协议，各族不会主动出动先天境以上的修者专门潜入和平区域，从事偷袭、暗杀等行动。

旋转门：在部分区域，官员们存在两重身份，例如海州，大海盗们多数都是商帮或是权贵的爪牙。

防御线：防御线是指所有非帝国秩序区域，存在名为“斩杀”的机制（即一旦发生某种特定情况，比如被超高灵能浓度污染）。
