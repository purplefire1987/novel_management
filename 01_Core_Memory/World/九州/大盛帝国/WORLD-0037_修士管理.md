# 大盛帝国·修士管理：玄部·镇灵台·封神序列

> 来源：`大盛帝国设定.md` ｜区间「**对修士的管理**」→「鸿钧分析机」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写、未补写。

## 一句话定位

玄部之下山水台管灵牒公文、镇灵台管追捕镇压；推金册评级通缉，封神序列提供机动力量，雷部与火部是皇帝直属的刀与牢。

---

1、帝国对修士的管理主要由“玄部”中的“山水台”和“镇灵台”负责。其中“山水台”负责对修士的灵牒发放、公文事务，“镇灵台”则负责追捕、镇压修士，其中“封神序列”则是为“镇灵台”提供机动力量。

2、推金册：帝国每过数年会对所有不受管理的修者按照危险程度进行综合评级，并发布和悬赏通缉这些人。这本小册子被称为“推金册”。

3、“封神序列”：帝国追捕和镇压普通犯案修士的主要力量，其成员享有帝国俸禄、官员权利，但无实际职事。一般会规定每年相应的任务数量。

4、镇灵台雷部：帝国最锋利的刀，皇帝直属的内卫，帝国镇压反对派、谋反修者等的主要力量。

5、镇灵台火部：帝国对高级修者和重要罪犯的监狱及管理机构。
