# 大盛帝国·军制与武装力量

> 来源：`大盛帝国设定.md` ｜区间「**帝国军旅**」→「通用机兵」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写。
> 例外：文末「编制层级」一节为 2026-11-05 补注，不在原文内，已单独标注来源与可信度。

## 一句话定位

超凡时代的常备军：玄术士与兵士两条极端路线并行，地方军与中央军相互牵制，禁卫系、精锐军团、常规军团三层序列。

---

帝国统一九州后，除了经济的发展之外，在科技上也有了极大的进展，其标志就是在六世皇帝期间，汽轮机与分析机的发明。在武器方面，汽铳逐渐成为社会维持治安的基本武器。在这个超凡横行的时代，最初的汽铳（依靠小型化高压水汽喷射而发射弹丸）并不是可以随便杀死修者的武器（除了某些低等修者的脆弱部位），为了增强杀伤力，汽铳的重量、出力不断增加，对铳手也提出了更高的素质要求。小规模战斗中，肉搏战仍然是最佳杀敌方式之一，刀剑不仅没有被淘汰，反而坚定的屹立了多年；大规模战争则不同，汽轮机在军事上的应用令修者头疼，军用强击型武器系列的破坏力相当惊人，一击约等于先天境玄术士的拿手玄术，虽然受限于散热等方面，然而一个先天境界的玄术士体内的灵力仅能撑起使用十数次这种等级的玄术。另外由于多年的储备，帝国军队也拥有一定量的巨型汽动兵器-力士系列。此外，灵能相关的各种物品也已经逐渐进入到民众的生活，目前的灵能制品主要用于帝国的大型公共设施领域，平常人所接触到的物品更多属于日用。帝国将利用“汽轮机”打造出了浮空之城（称之为白玉京），顶层的权力人士们居于白玉京之上，白玉京亦是帝国最大的空中军事堡垒。帝国的军事实力，目前走向两个不同的极端，专研灵能的“玄术士”体系以及常规武装力量的“兵士”体系。帝国的主要武装力量体系分为禁卫系、精锐军团、常规军团，常规军团一般自有称号，以各州划分战区维持各地治安及参与帝国战争，其中北府军和卫戎军战力最强，帝国兵工院目前正在针对最新型的设备来改良士兵的装备；兵人的标准装备有燧发铳、高压步铳、多用途战斗服、战刀；帝国有三大王牌步军“锐士”、“武卒”、“嵬兵”，四大骑军“千乘”、“刀骑”、“陷阵”、“虎贲”。玄术士体系则归属不同的序列，目前帝国推出了天下四凶作为明面上的对外宣传小队。

帝国的军制：帝国的军队分为两大势力，地方军和中央军，各州镇守各领一州军队进行州务防备、军事训练、兵役等任务，由皇帝、大宰、总帅和计相进行权衡。

### 集团军群的口径：三军是下限，三十万是满编（2026-11-05 作者裁定）

上将军条同时写了「30 万人以上」与「3 军定上将」，两个数不是同一个量：

- **三军＝下限**。编够三个军就能授上将军，按 3–5 万／军折算，**约 9–15 万**。这是「够格」的门槛，不是标准编制。
- **三十万＝满编**。要凑到三十万以上，按 3–5 万／军折算**需 6–10 个军**。这是倾国之力的理论峰值。

两者之间是常态。写点兵场面时按这个梯度取词：

| 说法 | 实指 | 分寸 |
| --- | --- | --- |
| 「三军」 | 9–15 万，刚够授上将 | 一个方向的方面军，够镇一州 |
| 「十来万」 | 4–5 军 | 帝国一次战役的常见投入 |
| 「三十万」 | 满编，6–10 军 | 倾国之力，非灭国之危不动 |

其余两点用法：

- **「上将军」极少实领**。三品而统三十万，已是帝国兵权的极限；写某人真坐这个位子，等于给了他造反的本钱，剧情上要给对应的猜忌。
- **旗是实用单位**。一旗 100–300 人，是一个主角带得动、也打得光的上限；五品郡守调不动一旗，知县更不必谈。
