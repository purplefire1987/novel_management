# 大盛帝国·政治：皇帝与七人议会

> 来源：`大盛帝国设定.md` ｜区间「**政治**」→「**传统、文化与教育」｜录入批次 `LORE-20261104-015157`｜原文照录，未改写、未补写。

## 一句话定位

顶层是皇帝与七相（大宰、总帅、大司空、大司礼、大司寇、计相、大司命）的「阁内议事」，其下是郡县州府与庞大的吏员金字塔。

---

帝国顶层势力多在中州，各州有本土势力；中州是帝国的定都之地，是顶级势力的博弈之所，帝室则有一锤定音的能力。

家族门阀：帝国家族门阀数百年间浮沉，声势仍盛的仅有数家，这数家高门中有四支出于陵州，被合称为“陵州四阀”，陵州四阀传承数百年，在陵州一代享有盛誉，祖辈累居高官，成为皇帝的心头之患。目前，各大门阀对于冬河会的行动抱有旁观的意味，他们是潜在的同情者，毕竟他们最希望的是“皇帝与门阀共治天下”。

皇帝及七人议会：这是整个帝国的最顶层建筑，掌控了整个帝国的走向，帝国任何下发的决策，都是由皇帝及七人商议后，再正式通知到整个帝国，这就是“阁内议事”。皇帝是帝国的统治者，七相则是帝国的大脑，包括大宰、总帅、大司空、大司礼、大司寇、计相、大司命。这七位负责内政和外交的顶级官员，拥有丰富的行政经验和政治智慧，负责管理帝国各类事务，确保帝国的统一和繁荣。同时，他们也代表帝国与其他势力进行外交交涉，维护帝国的利益和声誉。当今皇帝深居简出，七首常常私下议事，互通意见，这被称为七人议会；其下则是分配往各区域的中层管理者——普通官员们；最下则是庞大的底层吏员；这些人共同构成了整个帝国统治结构的金字塔。

在政治体制上是士族-地主政治形态，采用君主专制下的分权统治结构，大盛采用郡县州府制度，与官员共治天下。在阶级上，帝国有多个阶级，比如贵族阶级、官员阶级、修者阶级等，帝国也吸收了多个古代学派，比如大宰和大司礼吸收了仁理学派，大司空吸收了部分工匠学派，计相吸收了商学派，大司寇吸收了律法学派，军部和总枢吸收了兵家学派，大司命则吸收并管理着各类修者们。
