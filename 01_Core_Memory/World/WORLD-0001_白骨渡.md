# 白骨渡·世界设定

## 世界规则（硬约束）
- 北境长夜每年持续一百二十日，夜中「蚀气」弥漫，活人在野外过夜会被蚀气侵入。
- 蚀气入体者称为「染者」，染者会逐渐失去对自身姓名与记忆的掌控。
- 唯有镇夜司的「灯符」可在夜间维持小范围清明，灯符由人血点燃，一盏灯符可燃一夜。
- 死者不可复生。任何「复生」皆为他人误判、替身或认知错误，此为世界级硬规则。

## 力量体系与代价
- 修行者以「气」驭物，气有量，用尽需静养，强行透支会留下不可逆损伤。
- 断水刀一类的旧兵可承载气，但每次承载都会在同一处留下裂痕。
- 无人可同时操纵两件以上承载物（本章及以后不得违反）。

## 社会结构与权力
- 镇夜司：北境官方夜防机构，掌灯符，编制森严，内部有「清册」制度记录染者。
- 灰衣教：民间教派，宣称可「洗净蚀气」，实则以人换人，被镇夜司列为邪教。
- 渡口行会：控制白骨渡两岸摆渡，收取过河钱。

## 历史年表
- 长夜三十七年：白骨渡惨案，三百船工一夜失踪，官方记为「蚀潮」。
- 长夜四十一年：镇夜司设渡厄城分司，沈砚入司。

## 禁忌与不可违反项
- 不得让任何角色在无灯符的野外长夜中安然无恙。
- 不得让染者自行恢复记忆。
- 不得出现死者复活。
