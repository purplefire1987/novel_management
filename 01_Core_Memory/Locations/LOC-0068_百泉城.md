# 百泉城

> 来源：`九州-世界观资产.xlsx` · 工作表「地图库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

泉群众多、水量丰沛，城内百泉争涌，汇流成的护城河流淌到大明湖，与周围群山构成了独特的风光，成为少有的集“山、泉、湖、河、城”于一体的城市，号称“家家泉水，户户垂柳”、“四面荷花三面柳，一城山色半城湖”。
