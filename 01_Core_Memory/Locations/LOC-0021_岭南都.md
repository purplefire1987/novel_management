# 岭南都

## 概要

岭南是一个近代兴起的商业都市，其标志性建筑物是位于城北的天下第一高楼【白云楼】。岭南分为南北两个区域，北区是大型商店和公共设施的聚集地；南区是私人商店和住宅林立的居住区。岭南出了很多有名的大商人，广府、潮汕、惠嘉三大商帮鼎足而立。在巅峰时期，越商的财富甚至可与帝室相媲美，可以说岭南有今天的繁荣很大程度归功于他们多年的奋斗。但在岭南早期，这里因为地处偏远，很多不服朝廷的强力修者远遁于此，建筑、风俗不与世俗相同，时不时还有零星叛乱，封地在此的王侯常常与帝都公然唱反调，于是留下了“妖都”的名号。岭南的支柱产业是蔬果业、竹木业、药材业。舞龙舞狮是岭南的传统庆典
