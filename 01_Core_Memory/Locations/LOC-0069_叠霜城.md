# 叠霜城

## 概要

帝国最大的产盐之地，城内有超过1万户的盐民，因而也催生了最大的帮派-“盐帮”

## 档案

- **州属**：海州
- **府属**：黄龙府
- **郡属**：海盐郡
- **备注**：盐场：青州最大的产盐场所，由户部直管
