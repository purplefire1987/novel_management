# 金陵都

## 概要

得天独厚的地理位置和气度不凡的风水佳境催生了这座迷幻的城市。金陵织造局繁花似锦，各种情报贩子们游走动荡，情报争斗诞生的“恶之花”——谎言与欺骗充斥着这个城市。形形色色的人们杂居于此，发达的娱乐业和服务业让这里纸醉金迷、风月无边，欲望让这里的每个人都像是着了魔一样。因而这里也被世人称之为“魔都”。金陵目前的支柱产业是纺织业、偶像业与金融业

## 档案

- **州属**：扬州
- **府属**：余杭府
- **郡属**：江宁郡
