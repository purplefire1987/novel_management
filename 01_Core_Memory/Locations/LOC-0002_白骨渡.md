# 白骨渡

## 地理与环境
- 位置：白水河最窄处，南北两岸相隔约二百步
- 气候：河面终年有雾，长夜时雾里带蚀气
- 地形：东岸为石阶渡口，西岸为白骨滩与废祠高地
- 规模：可同时停船六艘

## 重要设施
- 东岸灯楼：一盏主灯符，守灯人两名
- 西岸废祠：灰衣教据点（沈砚尚未确认）
- 老陆船屋：西岸滩头，单间木屋

## 控制权与势力
- 东岸：镇夜司与渡口行会共管
- 西岸：名义无人管，实际灰衣教活动

## 历史事件
- 长夜三十七年：三百船工一夜失踪，仅老陆生还

## 当前状态
- 夜禁后禁止摆渡，但仍有私渡。
