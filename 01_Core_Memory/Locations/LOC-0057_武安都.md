# 武安都

> 来源：`九州-世界观资产.xlsx` · 工作表「地图库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

湖州的都城，因接壤四州成为交通枢纽，也号称“九府通衢”。这里也是汽轮机最发达的运用之地，得益于大型机车的普及，铁轨逐渐遍布九州，其标志性建筑是综合性研究机构【重工坊】和楚河边上的【鹤楼】。楚河横亘在武安城中间，由栈桥连接两岸，岸旁甚至有数个超过万人的大型工坊。该市的主要经济构成是重型机械制造与加工，同时运输业也特别发达。武安拥有九州最好的学生资源。武安被分为四大区域，“武、光、楚、汉”，其中光区位于楚河以东，是工坊的主要驻地，蒸汽化程度最高的地方；楚区位于楚河以西，水上交通便利，因而主要是商业区和运输枢纽（内陆港口，漕帮势力）；武区在光区北部，属于市政区、学区，不少学院也坐落在这里；汉区则是楚区南部，楚河与汉水交汇之地，属于千湖地带，物产丰富，不少居民在此处聚集，主要是渔猎区

## 档案

- **州属**：湖州
- **府属**：江陵府
- **郡属**：江陵郡
- **备注**：重工坊（工部）：隶属奉天造，是九州最大型的综合研究机构、专攻蒸汽与灵能的新技术，内部分为若干研究院与试验区，层层森严。鹤楼：鹤楼矗立在楚河之畔。虎跳涧
