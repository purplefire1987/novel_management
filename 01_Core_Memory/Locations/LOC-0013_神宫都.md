# 神宫都

## 概要

神宫位于不周山遗骸的山脊之上，依山而成，其标志性的建筑物是【云天宫】。苍州民居以“云天宫”而中心，向外放射状自然分布形成群落，围绕“云天宫”的是环形圣路“八角街”（八卦）。神宫因地形复杂，因而建筑普遍低矮，设计上多是采用飞檐型的屋顶，这里受到蒸汽变革的冲击不强，民众更尊重和敬畏传统，与外界的交流多半是互市时期。由于这里是九州的最高点，很多修者都曾在这里留下记号。神宫的支柱产业是珠宝业和精细雕刻业
