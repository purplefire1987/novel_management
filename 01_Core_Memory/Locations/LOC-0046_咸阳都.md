# 咸阳都

## 概要

陇中平原最大的都市咸阳，第四纪元时曾是人类古都“皓京”的所在地，其标志性建筑物是【人祖太庙】，供奉先祖英烈，帝国迁都中州后将“皓京”更名为“咸阳”。咸阳内有三宫六院108坊市，外有四大雄关（分别为潼关、大散关、武关、秦塞关）扼险要之地，曾被认为是人族摇篮、永不陷落之城。据说，咸阳内藏有至宝“太极图”（城内有108道古代“符刻”组成了形似太极图的阵法，这阵法是古神所布，经过古人类数百年的尝试，才找到了正确的启动方法，然而直到现今，人类也并未完全掌握这个符刻大阵）。由于蒸汽列车的兴起，曾经的四塞之地因为难以修建铁路，逐渐被认为是封闭之城，城市地位逐渐衰落。咸阳的支持产业是陶业、农业和教育业（文学）。这里的风俗是每年的人祖大祭
