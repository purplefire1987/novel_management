# 上京都

> 来源：`九州-世界观资产.xlsx` · 工作表「地图库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

帝国的政治文化中心。帝都以帝宫为中心左右对称分布，帝宫以“左祖、右社、面朝、后市”的原则建设，周围环绕着高数十米、长数千米的宫墙。帝宫以外，聚集了自动化港口、各地臣属驿馆、商业街等设施的地方是南城区，民居、酒楼等娱乐生活部分是西城区（靠帝宫的部分是显贵区，外部是平民区），工业等设施所在的地方是北城区，禁卫军演练、驻扎则位于东城区，皇家园林则位于东城区以外。由于每年都举行的国诞日和各种类型大会，所以吸引前来观光的旅游人数也很多
