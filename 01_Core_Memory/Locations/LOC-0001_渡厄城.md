# 渡厄城

## 地理与环境
- 位置：北境白水河南岸，正对白骨渡
- 气候：长夜期间极寒，白日短暂阴冷
- 地形：依崖而建的梯形城，东高西低
- 规模：三万户，长夜期间约两万人在城内

## 重要设施
- 镇夜司渡厄城分司（东城最高处，悬九盏长明灯）
- 药铺「半盏堂」（苏未晞坐堂，西市口）
- 东岸渡口与灯楼（守灯人每夜换符）

## 控制权与势力
- 官方：镇夜司（夜禁、灯符、清册）
- 民间：渡口行会（摆渡、抽成）
- 暗中：灰衣教在城内设有两处联络点（尚未查明）

## 历史事件
- 长夜三十七年：白骨渡惨案，全城戒严四十日。
- 长夜四十一年：设分司，沈砚入司。

## 当前状态
- 夜禁提前一个时辰，灯符配给削减三成。
