# 安顺都

## 概要

位于怀柔府大森林的安顺是一座年轻的都市，安顺的寓意是皇帝希望与蛮族的交流安稳温顺，其标志性建筑是擎天之柱】。帝国高层认为“非我族类、其心必异”，安顺这里施行的是军事化管理，也是抵御蛮族反扑的大本营。安顺像城寨多过都市，内部的巷子互相连接，纵横交错，巷子又直通街道，形成内部防御体系，城寨周围是屯堡，用来抵御蛮族。由于小规模战争不断，这里的走私业十分发达。戎州的支柱产业是矿业（特别是灵晶）
