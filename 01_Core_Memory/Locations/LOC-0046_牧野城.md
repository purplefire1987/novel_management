# 牧野城

> 来源：`九州-世界观资产.xlsx` · 工作表「地图库」｜录入批次 `ASSETS-20261103-224145`｜旧稿资产，如与新正文冲突，以正文为准。

## 概要

放牧与野兽出没之地，其标志性建筑物是“金顶大帐”，位于广阔无垠的金帐草原，这里过去曾经是蛮族的地盘，现在则是帝国放牧之所，号称“帝国碧玺”，金帐草原的深处仍然有叛军在活动。
