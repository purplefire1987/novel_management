# 天眼术

> 所属技能库：[[WORLD-0015_技能库_方术|方术]]｜品级：下品｜系别：法术类

- **品级**：下品
- **能力系别**：法术类
- **咒语**：天法清清，地法灵灵，阴阳洁净，通天达地，天眼，开！
- **效果**：一个时辰内，可以看见很远或极细微的物体，需要持续消耗灵力
- **备注**：需要新发的柳树叶
