# 诏令：镇

> 所属技能库：[[WORLD-0023_技能库_玄法|玄法]]｜品级：中品｜系别：法术类

## 档案

- **品级**：中品
- **能力系别**：法术类
- **咒语**：天皇御极，八方威镇，诏曰：镇封尔身，禁断灵机！
- **效果**：镇压敌人灵机运转，使目标灵能/法力大幅受限，普通灵能者当场丧失法力运转能力；对高阶灵能者可封锁灵力通道，削弱五至七成战力。
- **备注**：需要帝国官印
