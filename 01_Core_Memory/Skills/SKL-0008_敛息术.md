# 敛息术

> 所属技能库：[[WORLD-0015_技能库_方术|方术]]｜品级：下品｜系别：法术类

## 档案

- **品级**：下品
- **能力系别**：法术类
- **效果**：在一个时辰内，全身陷入假死状态
- **备注**：2026-11-05 作者裁定——玄法侧曾有一张同名卡（SKL-0131，效果为「收敛气息、需无根草」），已删除，全库「敛息术」以此卡为准，即**假死**，不是收敛气息。写作时若要写「屏息藏形」，另立新技，不要借用本名。
