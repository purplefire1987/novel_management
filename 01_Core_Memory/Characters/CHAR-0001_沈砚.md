# 沈砚

## 基本信息
- 身份：镇夜司渡厄城分司校尉，掌东岸夜巡
- 年龄：二十九
- 外貌：左眉有一道旧疤，惯穿洗得发白的玄色短打，佩刀不佩剑
- 性格：寡言，讲规矩，宁可慢一步也不越界
- 目标：查清白骨渡惨案的真相，找回师父当年失踪的记录
- 核心欲望：让死去的人被记住名字
- 核心恐惧：自己有一天会忘记师父的名字

## 能力与限制
- 能力：气感极准，能在十步内判断一个人是否染者；刀法走守势，极少主动抢攻
- 代价：每次以气驭刀，左肩旧伤会复发，夜里会渗血
- 限制：只可操纵一件承载物（断水刀），不可同时驭二物
- 弱点：不肯在未确认事实前动手，遇熟人容易迟疑

## 人物关系
- 关系对象：苏未晞
- 关系性质：旧识，互相有未说出口的亏欠
- 当前状态：表面疏离，实际互相照应（见 REL-0001）

## 人物弧线
- 起点：只信清册与规矩
- 转折：发现清册本身可能被人改过
- 终点预期：学会在不完美的证据里做判断

## 重要事实
- 沈砚不知道苏未晞曾在灰衣教中待过。
- 沈砚的师父「陆听寒」于长夜三十七年失踪，官方记为死亡，沈砚从未接受。

## 作者备注
- 沈砚的语言要短，不要长篇解释。
