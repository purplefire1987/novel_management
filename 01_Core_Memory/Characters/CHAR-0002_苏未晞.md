# 苏未晞

## 基本信息
- 身份：白骨渡药铺坐堂，兼替渡口行会记账
- 年龄：二十六
- 外貌：总穿一身素白，右手腕系一枚旧铜铃
- 性格：说话轻，判断狠
- 目标：找到失踪的兄长苏行舟
- 核心欲望：把哥哥从「染者名录」上划掉
- 核心恐惧：有一天自己也会被写上清册

## 能力与限制
- 能力：通药理，能辨蚀气深浅；铜铃可短暂扰动他人的气感
- 代价：铜铃每响一次，她自己会失一段短时记忆（数息到半个时辰）
- 限制：铃响不超过三声，第四声会让她彻底忘记当日之事
- 弱点：一旦涉及兄长，判断会失准

## 人物关系
- 关系对象：沈砚
- 关系性质：旧识，彼此试探
- 当前状态：合作但互不交底（见 REL-0001）

## 人物弧线
- 起点：只为兄长做事
- 转折：发现兄长并非被害，而是主动入了灰衣教
- 终点预期：在真相与亲情之间做出选择

## 重要事实
- 苏未晞曾在灰衣教做过两年药童，此事沈砚不知。
- 苏未晞知道沈砚的师父与兄长失踪是同一夜。

## 作者备注
- 她的谎言从不说满，永远留半句。
