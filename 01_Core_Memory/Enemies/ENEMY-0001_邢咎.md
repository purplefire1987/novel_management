# 邢咎

- 身份：灰衣教执事，负责西岸「收人」
- 目标：凑齐本届「换命」所需的一百二十名染者
- 能力：以灰布束人气血，被束者无法呼救；熟悉镇夜司的巡夜路线
- 弱点：右腿在长夜三十七年被打断过，走不了急路
- 资源：教中人手二十余、西岸废祠、伪清册
- 与主角关系：杀师嫌疑对象之一（未证实）
- 当前状态：在逃，最后一次出现在西岸（CH-0001 后客观状态：未被确认死亡）
- 已知情报：知道沈砚的巡夜习惯
- 未知情报：不知道苏未晞曾入教

## 备注
- 沈砚在 CH-0001 推测邢咎已死，但正文没有尸体、没有确认，故客观状态仍是「生死未明」。任何章节不得将其当作已确认死亡处理。
