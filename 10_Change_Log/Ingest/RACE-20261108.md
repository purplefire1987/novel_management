# 种族表三级化 + 人物/敌人 race 回填｜RACE-20261108

> 本批**无 `OP-` 操作号**（未走 `novel ingest` / `import-*` 事务），回滚靠 Git revert
> 或下方备份文件。执行时仓库处于 `.git/index.lock` 死锁状态，按主理人指示**未执行任何 git 命令、未打快照、未重建索引**。

## 为什么手改，而不是跑 CLI

`novel --help` 共 27 条命令，**没有**任何「编辑既有档案 frontmatter / 批量回填字段」的受控通道：
`new --set` 只在新建时生效，`annotate` 只作用于章节作者备注，`import-*` 是整批重建。
因此单字段回填只能改 Markdown 再 `novel rebuild-index`——这是系统既成设计，不是绕路。

## 改了什么

### 1. `WORLD-0025_种族表.md`：平铺 → 三级

| 维度 | 改前 | 改后 |
|---|---|---|
| 结构 | 35 个 `## 族名` 平铺，无分组 | `## 属`（8 个）› `### 族`（35 个）› 关联双链（个体） |
| frontmatter | — | 新增 `race_groups`（属 → 族名单，机器可读）；`subtype` / `source_refs` / `import_batch` 原样保留 |

| `关联：敌人库` | 无 | 新增，75 个敌人双链，构成三级结构的个体层 |
