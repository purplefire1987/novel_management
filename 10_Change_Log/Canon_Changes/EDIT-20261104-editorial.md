# 编务变更记录 · 2026-11-04

## 1. 「待建实体」误判：根因与修复

- **现象**：`VOL-0001 工坊疑云` 的待建实体清单列了 12 项，其中 **5 项库中本来就有档案**：
  环教、长桑公、桃霄、明工造老坊主、老坊主孙女。
- **根因（两条，缺一不可）**：
  1. **工具缺口**：CLI 只有 `search`（章节全文检索）与 `show <ID>`（按 ID 看详情），
     没有「按名字查实体档案」的命令。录入时只能用"名称完全一致"的人工比对，
     遇到**简称**（环教 → 环之教派）、**职务称呼**（老坊主 → 安怀舟）、
     **亲属指称**（老坊主孙女 → 安宁宁）必然判"无档案"。
  2. **流程缺口**：`intake_clerk` 提示词只写了"双链只连已存在的 ID"，
     没要求逐条落库核对，于是"读稿印象"直接进了清单。
- **修复（工具）**：新增 `novel find <关键词>`——
  `Index.search_entities()` 对 `name` / `aliases` / `summary` 做子串检索，
  排序优先级「名称命中 > 别名命中 > 概要命中」；命中即给 ID，未命中才可列待建。
- **修复（数据）**：补登记别名，使三种叫法都能命中同一条档案：
  | 档案 | 新增 aliases |
  |---|---|
  | `FAC-0025 环之教派` | 环教、环之教 |
  | `CHAR-0026 安怀舟` | 老坊主、老工坊主、明工造坊主 |
  | `CHAR-0006 安宁宁` | 坊主之女、老坊主孙女 |
  | `CHAR-0023 长桑公` | 黑馆使 |
  | `CHAR-0002 项月溪` | 夏月溪、十二皇女、公主 |
- **修复（流程）**：`00_System/Prompts/intake_clerk.md` 增「判库里有没有只认 `novel find`」一节，
  并把待建清单改为两段式：**已消解**（写明实际档案 + 为什么原名没命中）与 **仍需建档**。
- **同步**：`VOL-0001` 清单按上表重写，正文里的 桃霄 / 老坊主 / 老坊主孙女 / 长桑公 全部改挂双链。

## 6. 地图从零落成（`01_Core_Memory/Maps/` 一直是空的）

- **根因**：Maps 目录建库时只有 `.gitkeep`，从无生成逻辑。九州表只落成 `WORLD-0029` 一篇文本，
  「关联：地图库」那一行是给人读的字符串，从未被解析成「州 → 城」层级，所以地图是空的。
- **做法**：新增 `00_System/scripts/build_jiuzhou_map.py`（幂等，可重跑），三件事：
  1. 解析九州表 → 11 个州域档案（`LOC-0073` ~ `LOC-0083`），带下辖城双链；
  2. 生成 `Maps/九州地图.md`：方位、地貌、口语、城邑一页看全（71 城 + 1 府）；
  3. 生成 `Maps/九州地图.canvas`：中州居中、八州按真实方位环列的 84 节点方位图。
- **反向校验**：脚本读每个城档案的「州属」，补挂九州表漏列的城（本轮补出 `LOC-0072 怀柔府` → 戎州），
  并对「九州表 vs 档案州属」不一致逐条报警。本轮：零冲突。
- **编号幂等**：重跑复用已有州域档案编号，不会每次生成一套新号。

## 7. 索引被回收站抢占（`CHAR-0001` 指向示例人物）

- **现象**：把示例项目「白骨渡」移进 Vault 内的 `.trash_20261104/` 后，Bases 视图里仍有 `CHAR-0001_沈砚`，
  且 `novel show CHAR-0001` 返回沈砚而非陈默。
- **根因**：`vault.iter_markdown()` 只跳过 `.obsidian` / `.git` / `.novel_system` 三个定名目录，
  **没跳过所有点开头目录**。隐藏的回收站在 Vault 内，仍被扫描；示例档案的 `CHAR-0001` 与真档案同名，
  索引主键冲突后旧档取胜。
- **修复**：`iter_markdown()` 与 `cleanup_stale_temp()` 一律跳过 `d.startswith(".")` 的目录；
  回收站整体移出 Vault（`../.trash_novel_20261104/`）。
- **验证**：重建后 `character 86 / location 83 / faction 101 / item 333 / world 39`，
  `novel find 沈砚` 零命中，`CHAR-0001` 恢复为陈默，实体索引页 740 条零示例残留。
