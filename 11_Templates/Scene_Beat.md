> `sequence` 是**叙事顺序**，不是编号。同一章里必须 1..n 连到底，
> 「与下一场景的连接」只能指向 `sequence + 1`。两者不一致＝跳号，下一场起笔就接不住。

> 写成 `- 键：值` 会被静默跳过：时间倒退查不出来，还会倒打一条「没写与下一场景的连接」。

- **开场极性**：`+` / `-` / `±`
- **收场极性**：`+` / `-` / `±`
- **价值转变**：`full` / `weak` / `none` / `unjudged`
- **转折点落点**：（价值翻转的那一下，是哪句台词或哪个动作。不许写「气氛逐渐」）

> 开场极性与收场极性**相同**，就是非事件——合并进相邻场、删除，或补一次翻转。
> 唯一的例外是过渡场：极性可以不变，但读者必须多知道一件下文要用的事，
> 或角色必须多出一个之前没有的选项。两者都没有，就是零转变，不得发布。
> 判据全文见 `00_System/Prompts/story_editor.md`「场景拆解标准」。
>
> `价值转变` 这一行不能省：极性相同的场次只有它能把 `weak`（过渡场，靠信息增量过关）
> 与 `none`（零转变，不得发布）分开；没有它，两张卡看起来一模一样。

- **场景开始状态**：

- **期望**：（他以为会发生什么）
- **结果**：（实际发生了什么）
- **缺口（gap）**：（结果怎么偏离了期望；跟上一条对不上，说明这一场只是在执行计划）
- **危机两难 A**：（某个选择；代价：…）
- **危机两难 B**：（另一个选择；代价：…）

> 两难＝两个选项都付代价，且不能都要。一边免费的是**障碍**，不是危机；
> 两边代价同向同量的（「死得快／死得慢」）是**假两难**，选哪个都不改变价值。

## 闸门自检（写完删掉本节）

**结构**

- [ ] 主控价值只写了一个；写三个等于没有主控
- [ ] 开场极性与收场极性**不同**；相同的话，它是不是过渡场？信息或选项变了吗？
- [ ] 转折点落点指到了具体的台词或动作，不是「气氛逐渐」
- [ ] 期望与结果对不上（有缺口）；对上了就说明这一场没戏
- [ ] 缺口带来了反应：判断失误／付出代价／改主意，至少占一样
- [ ] 两难 A、B 两边都写了代价；有一边免费就先别叫它危机
- [ ] 情绪变化能从开场／收场极性推出来
- [ ] 这一场删掉，本章会缺东西吗？不缺 → 它是零转变，合并或删掉

**接缝**

- [ ] 上一场的收束画面，在这场第一段里有个着落（同一件物、同一句声、同一种冷）
- [ ] 时间只往前走；并行场景要写明「与第 N 场同时」，不许悄悄倒退
- [ ] 地点变了，就要交代怎么到的——一笔带过可以，不能凭空出现
- [ ] `carry` 里的每一条，在这场要么延续，要么写明它变了
- [ ] 字段都是 `- **键**：值` 形式（粗体漏了，接缝检查会静默失效）
