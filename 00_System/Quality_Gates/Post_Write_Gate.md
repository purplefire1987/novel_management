# 写后 Gate（Post-Write Gate）

记忆提交要成功，以下必须同时成立，任一失败即整体回滚：

- 作者已确认正文（章节状态 ≥ `author_approved` 且已 `published`）；
- 每条提案都有 `evidence`（正文句段）或章节引用；
- Schema 校验通过；
- 实体引用有效（`target_id`、`participants`、`location_id` 均存在）；
- 状态变化合法（不违反世界规则，不出现死者复活）；
- 重大 Canon 变化（死亡/复活、新世界规则、伏笔回收）已获作者批准；
- 连续性检查完成；
- 场景价值转变检查完成（判定时点在 `publish` 前，规则见下节）；
- 每场的「被迫反应」检查完成、每章末句的钩子检查完成（规则见下节）；
- SQLite 与文件一致（提交后重建校验通过）；
- 审计日志已写入；
- Git commit 成功，或失败原因被显式记录且不阻断已完成的文件写入（随后必须补提交）。

回滚要求：
- 有 operation ID；
- 有备份或 Git 可回退版本；
- 回滚本身进入审计日志；
- 回滚后重建索引。

## 场景价值转变（麦基口径）

判据全文见 `00_System/Prompts/story_editor.md`「场景拆解标准」；本节只写**怎么查、什么时候卡**。

**没有价值转变的场景不得发布。** 这一条不拦"写得好看"，它拦的是"这一场整场删掉、正文无损"。

| 检查项 | 判据 | 不通过时 |
|---|---|---|
| `scene_value_shift` | 每场结束时，读者对至少一个价值维度的判断被改写 | `REVISION_REQUIRED`，不得进入 `published` |
| `scene_forced_response` | 每场都写得出「谁被迫做了什么、代价是什么」；写不出＝观察场 | `REVISION_REQUIRED`，与 `scene_value_shift` 同级 |
| `chapter_hook` | 每章末句命中五类钩子之一，类型已在细纲 `钩子类型` 标明，且末句不是旁白总结 | `REVISION_REQUIRED` |
| `scene_dilemma` | 章内至少一处真两难（两个选项都付代价，且不能都要） | MAJOR，记审稿意见，不阻断 |
| `act_chain` | 本卷五段推进链（激励事件→进展纠葛→危机→高潮→结局）可指到具体**锚点章**，且五段跨度 ≥ 全卷章数的 1/3 | MAJOR，记审稿意见，不阻断 |
| `cast_motive` | 有权者把主角留在案子里／带进圈子，动机由**用人的一方**给出（他不用会损失什么、用了要担什么），且「最省事的做法」（直接结案／直接灭口）对他有代价 | MAJOR，记审稿意见；同一个角色连续三章给不出＝`REVISION_REQUIRED` |

**`cast_motive` 判的是「谁需要谁」，不是「主角多聪明」。** 主角被接纳只因为他有用，是最不成立的写法：
有用的人多得很，灭口更省事，而且赏识不需要理由、用人需要。
判法：把这一段的用人者换成另一个人，若剧情照样成立，说明动机没写在他身上，判不通过。
「对方给的位置是可弃的」（不占编制、不入册、随时可逐）通常是这条成立的标志——
若一开口就是「以后你就是自己人」，那不是用人，是作者替关系提速。

**`act_chain` 在卷级判，不在章级判。** 数据在 `04_Outline/Volumes/VOL-*_序列.yaml`，
不写在单章输出里——一章装不下五段幕。判之前先看分章表：卷有几章、五段锚点落在第几章。
若五段全挤在同一章或相邻两章内，不是"结构紧凑"，是压缩病，直接记 MAJOR 并回退到分章表。
"锚点跨度不足全卷 1/3"这条阈值就是为它设的：没有分章表时，这条永远判不出来，
所以**没有分章表的卷不判幕链，判 `unjudged`**——不得判通过。

### 怎么判（照着做，不靠"感觉"）

只读 `SCENE-*` 卡片与本场对应的正文段，不看作者说明、不看创作意图。

1. 每场先问第一句：**这场开始前，读者认为某个人／某件事是安全的／可信的／强的；
   结束时，这个判断变了吗？** 变了 → 写下开场极性与收场极性，判通过。
2. 没变，问第二句：**这一场里，读者或角色是否多知道了一件影响后续决定的事，
   或者多出了一个之前没有的选项？** 是 → 弱转变；不是过渡场则记 MAJOR。
3. 两句都是「否」→ **零转变**。处置：合并进相邻场，或给它补一次翻转。
   不许拿「气氛好」「人物立体」「信息量大」抵——这三样都不是价值转变。
4. 判完写进审稿意见，一场一行：`SCENE-CH-0002-003：− → +｜转折点＝石季崇问「你要什么」`。
   **没有这一行，等于没判。**

### 例外与边界

- **过渡场**允许弱转变：极性可以不变，但信息或选项必须变。允许的最弱形态是——
  读者知道了一件下一章要用到的事。连这个都没有，它就不是过渡场，是该删的场。
- **章的激励事件场**（本章第一场）以「本章处境是否被重置」为判据，不以极性翻转。
- **legacy 场景**（2026-11 之前由 `00_System/scripts/gen_scene_beats.py` 生成、
  不含结构层字段）：记 `unjudged` 放行——**不得**记为通过，也**不得**记为不通过。
- **判定不依赖字段是否存在**：字段空着不等于零转变，字段填满也不等于有转变。
  以细纲／正文读出来的事实为准；缺字段时只能判 `unjudged`。
- **时点**：本项在 `editor_approved` → `author_approved` → `published` 这一段判定，
  即审稿阶段做。已 `published` 的章节**不因本项被退回**——状态机没有
  `published → revision` 这条边，硬退会把章节卡成死状态。历史章节若判为零转变，
  记 MAJOR 供后续重写参考，不阻断下游。
- **只对新写／重写的章节执行**；已发布章节不追溯返工（作者点名除外）。

### 反规避

连续两场都靠「反转」撑，读者的阈值会被抬坏。本项问的是**判断有没有被改变**，
不是**有没有意外**。一段长戏可以只有一个真翻转，中间用弱转变垫——那不是不合格，那是节奏。

零转变长这样：一场人很多、话说得漂亮、情绪也饱满，但散场时任何人的处境、关系和认知
都和开场一模一样。

## 章末钩子与有效困境（作者 2026-11-09 裁定）

两条都只有一问，不许答成「差不多」：

**① `chapter_hook`：这一章的最后一句，凭什么让读者翻页？**

- 五类：未完成的动作／新的威胁／刚被推翻的认知／倒计时／一句听不懂的话。至少命中一类。
- 类型必须先在细纲的 `| 钩子类型 |` 里定死；正文写完回填 `章末钩子：<类型>｜<最后一句原文>`
  到写作备注。两处对不上 → 不通过（是改了钩子，不是写了钩子）。
- 末句是旁白总结的一律不通过：`他不知道这是最后一夜`／`后来他常常想起`／`一切才刚刚开始`。
  这三句的共同点是把读者的情绪提前结算掉。
- 相邻三章同一类型连用 → 记 MAJOR（不阻断，但要求改类型）。五类轮换，同类最多连两章。

**② `scene_forced_response`：这一场里，谁被迫做了什么？代价是什么？**

- 三选一：一个动作、一个决定、一次改判。三样都没有 → 观察场，合并或补动作。
- **「他没有选择权」不是免检。** 被架着走、四肢动不了、奉命行事，都可以有被迫反应
  （抓一把草、把话咽回去、不问、不停手）。答不出 `did` 才是问题。
- `did` 写得出、`cost` 写不出 → 记 MAJOR：有反应但没代价，读者感觉不到疼。

### 为什么这两项会空转，怎么防

`00_System/scripts/check_hooks.py` 只验**字段在不在、类型对不对**，
它验不出「钩子好不好」「反应是不是真的被迫」——那要人读。所以：

- 脚本报 0 违规，只说明**没有漏填**，不说明**写得对**。这是两种结论，不许合并汇报。
- 脚本报违规时，先看是不是细纲没标类型；细纲没标的，罚编辑，不罚主笔。
- 已 `published` 的章节不追溯（状态机没有 `published → revision` 这条边）；
  `--strict` 只在重写开工前对旧稿跑，用来给重写方案列缺陷，不用于卡发布。
