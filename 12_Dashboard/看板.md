## 七、孤立档案：没有任何页面链进来

以下是 `dataviewjs` 实时算的入链数。**孤立不等于错**——可能是还没写到，也可能是漏挂了关系。数值偏大时跑一次 `novel rebuild-index`，投影会补上该补的链。

```dataviewjs
const pages = dv.pages().where(p => p.type && p.file.path.startsWith("01_Core_Memory/"));
const inbound = {};
for (const p of pages) {
  for (const l of p.file.outlinks) inbound[l.path] = (inbound[l.path] || 0) + 1;
}
const orphans = pages.where(p => !inbound[p.file.path]).array();
const pct = pages.length ? Math.round((orphans.length / pages.length) * 100) : 0;
dv.paragraph(`档案 **${pages.length}** 份，其中 **${orphans.length}** 份无入链（${pct}%）。`);
if (orphans.length) {
  const byType = {};
  for (const o of orphans) byType[o.type] = (byType[o.type] || 0) + 1;
  dv.table(
    ["类型", "数量"],
    Object.entries(byType).sort((a, b) => b[1] - a[1])
  );
  dv.table(
    ["档案", "类型"],
    orphans.slice(0, 30).map(o => [o.file.link, o.type])
  );
}
```

## 八、连通块：知识库是不是一整个网

把每条双链当一条边做并查集。理想状态是**一块**——所有实体最终都能顺着关系走到彼此。块数偏多，说明有几撮素材还没接进主线。

```dataviewjs
const pages = dv.pages().where(p =>
  p.type && (p.file.path.startsWith("01_Core_Memory/") || p.file.path.startsWith("05_Story_Assets/"))
);
const byPath = new Map(pages.map(p => [p.file.path, p]));
const parent = new Map([...byPath.keys()].map(k => [k, k]));
const find = x => { while (parent.get(x) !== x) { parent.set(x, parent.get(parent.get(x))); x = parent.get(x); } return x; };
const union = (a, b) => { const ra = find(a), rb = find(b); if (ra !== rb) parent.set(ra, rb); };
for (const p of pages) {
  for (const l of p.file.outlinks) if (byPath.has(l.path)) union(p.file.path, l.path);
}
const groups = new Map();
for (const k of byPath.keys()) {
  const r = find(k);
  if (!groups.has(r)) groups.set(r, []);
  groups.get(r).push(k);
}
const blocks = [...groups.values()].sort((a, b) => b.length - a.length);
dv.paragraph(
  `节点 **${byPath.size}** 个，连通块 **${blocks.length}** 个；` +
  `最大 ${blocks[0]?.length ?? 0} 个，最小 ${blocks[blocks.length - 1]?.length ?? 0} 个。`
);
const loose = blocks.filter(g => g.length <= 5).slice(0, 8);
for (const g of loose) dv.paragraph("· 孤立小组：" + g.map(x => dv.fileLink(x)).join("、"));
```
