# 正式风格参考

## 视角
第三人称限知，紧贴沈砚；只写他能看到、听到、判断出的东西。

## 句法
- 平均句长 18 字以内，动作句更短。
- 少用形容词堆叠，多用具体物件（灯符、刀裂、酒气）。
- 心理描写不超过两句，用动作替代解释。

## 禁忌
- 不写「他知道自己必须……」式的自我解说。
- 不用现代口语、网络语。
- 不在正文中直接命名情绪，用身体反应写。

## 样段（来自 CH-0001，可作为节奏基准）
> 灯要灭了。沈砚没有回头，他知道回头也看不见什么。河上有雾，雾里有东西在走。他把刀横过来，刀背上的裂口贴着手心，凉的。

## 对话
- 沈砚：短句，常省略主语。
- 苏未晞：句子完整但留半句，用反问收尾。
- 老陆：绕，先说天气，再说正事。
