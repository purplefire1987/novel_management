# 当前活跃上下文

## 正在写
CH-0002《渡口无灯》

## 这一章只有三件事
1. 沈砚必须在天亮前到西岸。
2. 老陆不肯开船，直到看见沈砚左肩的血。
3. 船到河心，灯符灭。

## 这一章绝对不能做
- 不能让邢咎以任何确定形式出现或被确认生死。
- 不能让刀鞘第二道血痕被解释（FORESHADOW-0001，窗口 CH-0004～CH-0008）。
- 不能出现第二个承载物。
- 不能让苏未晞说出自己入过灰衣教。

## 语气提醒
- 冷、短、有铁锈味。句子不要太长。
