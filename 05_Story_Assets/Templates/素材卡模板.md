# 素材卡模板

> 复制本文件到 `Battles/` `Dialogue/` `Emotional_Beats/` `Highlights/` `Sensory/` `Settings/`
> 任一目录，改 id 与内容即可。id 格式 `ASSET-0001`（见 `00_System/Config/id_rules.yaml`），
> 全库连续编号，不按分类分段。

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | `ASSET-\d{4}`，全局唯一 |
| `name` | 是 | 卡片名，用**手法**命名而不是章节名（「三段式围杀」比「第 2 章」有用） |
| `category` | 是 | `battle` / `dialogue` / `emotional_beat` / `highlight` / `sensory` / `setting` |
| `canon_status` | 是 | 摘自旧稿的填 `deprecated`；新写的填 `proposed` |
| `tags` | 是 | 3–5 个，供检索 |
| `source_refs` | 是 | 原文相对路径，必须真实存在，否则 `novel integrity` 会报断链 |

```markdown
id: ASSET-0000

- 标签二

---

# 卡片名

> 摘自旧稿 `CH-1002_xxxx`｜`canon_status: deprecated`：新稿可借用其**手法**，不得照抄文字。

## 适用场景

- 什么情况下翻这张卡（写哪类场面时用得上）。

## 资产内容

> 原文摘录。**原样保留**，包括错字与旧地名——这是史料，不是范文。

## 可复用点

- 拆到「手法」层面：结构、节奏、句式、视角、道具用法。不要写「写得好」这种废话。

## 使用限制

- 哪里不能直接用：语感过时、设定冲突、用多了会通货膨胀。

## 风格标签

标签一、标签二

## 关联

- [[CHAR-0001_陈默]]
```

## 使用纪律

- **素材卡不是正文**。翻卡是为了想起「这个手法可以怎么用」，不是把段落搬进新稿。
- 一张卡只讲一个手法。塞了三件事的卡，写的时候一件也想不起来。
- `canon_status: deprecated` 的卡，引用时必须重写句子；`proposed` 的卡（新素材）可以直接用得近一些。
- 卡片被用过之后，在「关联」里补上落地章节（如 `- 已用于 `CH-0012_xxx``），方便回溯哪些手法已经用过、会不会重复。
