# 大盛官制与军制速查

> **性质**：派生速查卡，不是独立设定源。全部条目由 [[WORLD-0027_帝国官职表|帝国官职表]]（164 条）、[[WORLD-0028_帝国爵位表|帝国爵位表]]（9 条）、[[WORLD-0031_军制与武装力量|军制与武装力量]]、[[WORLD-0034_政治与七人议会|政治与七人议会]]折算而来。
> **冲突处理**：与上述四表不一致时以四表为准，并回来改这张卡。旧稿摘录口径（七部并立、司星台）已作废。

## 适用场景

- 写朝廷、军队、地方军政场面时，一句话交代清楚「这人管什么、能压住谁」。
- 新造一个官职前先在这里找同类项，别在七部之外另起一套平行体系。
- 校验人物的权柄是否越界：**官阶压不住的事，他不能办；爵位不够的位子，他坐不上**。

## 一、顶层：皇帝 + 七人议会

决策只出一个口子——「阁内议事」：皇帝与七相同议，议定后下发全国。

## 三、七部与其下属

| 部 | 下属署司台院 |
| --- | --- |
| 吏部 | 考功司（考评升迁）、邮驿司（驿道邮传）、靖卫司（城防消防、通明境以下修士管理）、中书省（诏书行文）、御史台（监察百官） |
| 户部 | 平准署（市价、税吏）、度支署（预算、金融、统计）、典仓署（粮盐铁钱）、市舶署（海关漕运）、织造署（明面纺织，实为情报经费与掩护） |
| 刑部 | 司门司（关渡禁令）、刑狱司（各级监狱）、大理寺（最高法、重案复核） |
| 工部 | 将作院（工匠调度、金玉器皿灵器）、冶铸院（冶炼）、兵工院（军工，下辖奉天造）、研造院（帝国科研院） |
| 礼部 | 太学（科考教育）、鸿胪寺（外交）、进奏监（舆情监控）、太庙、太医院、昭文馆（书籍）、太乐府 |
| 兵部 | 典军处（作战筹划、军情、烽燧、军档）、甲备处（粮秣被服兵器坐骑、军事科研） |
| 玄部 | 观星台、山水台、镇灵台、雷部、火部、封神序列、城隍府、水伯宫、北界诏狱、铸币监 |

**玄部一层要单独记住**，因为它不像别的部：

- **大司命**（从一品，内阁）总管三台，是七相之一，不是「玄部尚书」。
- **少司命**（从二品，亚卿）管内务府、宗人府、御膳房、御医房、内仓——**皇室家务**，与修行事务无关。这是最容易写错的一处。
- **观星台**：观星、占卜、历法，兼守南天门。主官司星玄君（从三品）。
- **山水台**：灵牒发放、公文传递、职称评定、奇物管理、机密情报通道与加密。主官山水玄君（从三品）。
- **镇灵台**：镇压通明境以上修士、追捕、镇压奇物。主官镇灵玄君（三品）。下辖**雷部**（皇帝直属内卫，四个惩恶小组：饕餮、混沌、穷奇、梼杌）与**火部**（皇狱，关高级修者）。
- **封神序列**：给镇灵台提供机动力量，成员领俸禄有官身而无实职；四大分属为句芒（首领代号「姜」，执神农鞭）、祝融（「重黎」，重瞳，融光神通）、蓐收（「石」）、共工（「龚」）。

## 五、军制：两条路线、三层序列

**两条路线并行**：专研灵能的「玄术士」体系，与常规武装的「兵士」体系。兵人标准装备是燧发铳、高压步铳、多用途战斗服、战刀；对付修者靠军用强击型汽动武器（一击约等于先天境玄术士的拿手玄术，但受散热限制）。帝国另存有巨型汽动兵器「力士」系列。

**三层序列**：禁卫系 → 精锐军团 → 常规军团。常规军团自有称号，按州划战区，**北府军**与**卫戎军**战力最强。

**王牌**：三大步军——锐士、武卒、嵬兵；四大骑军——千乘、刀骑、陷阵、虎贲。

**两大势力**：地方军与中央军。各州镇守领一州军队，管州务防备、军训、兵役，由皇帝、大宰、总帅、计相四方权衡——**这是文武互相牵制的机关，写调兵戏时别漏掉计相的钱袋子**。

**编制与兵力**：八级编制（集团军群 → 军 → 校 → 团 → 营 → 旗 → 队 → 伍）、各自主官品级与爵位门槛，
见 [[WORLD-0031_军制与武装力量|军制与武装力量]]「编制层级」一节。本卡不复述——
那张表原先只活在本卡里，2026-11-05 已升为设定源；兵力数值的真正锚点在
[[WORLD-0027_帝国官职表|帝国官职表]] 各级武职的说明列，改数字去改官职表，0031 是汇总视图。

**地方军命名**：一州一军，以州名或别名命名。湖州＝[[FAC-0085_千湖军|千湖军]]。

## 六、写正文时的四条自检

1. **称呼对不上就是错**：大司命是七相，不是「玄部大人」；少司命管皇家内务，不是「大司命的副手」。
2. **越权要有代价**：五品郡守调不动一旗兵；知县更调不动。想让他调兵，先给一个「持节」「权宜」的说法，或者让他借势——借谁的势要写清。
3. **服色是给读者看的**：不必报官名，写「朱袍」「青金」读者就知道分量。金印一亮，场面自动安静。
4. **爵位别乱赏**：非军功不封爵。想给主角一个爵，先给一场仗。

## 使用限制

- 官职表 164 条里，多数条目没有指定任职人；**写具体人物前先在表里查有没有人占位**，避免撞车。
- 表中「相关人物」栏只填了十余个（吴仕贞、李钧、卢景元、朱安丞、魏玄、萧瑜、夏瑶华、张香韬、石季崇、老贺、常空、周景瑜、项旒、姜伯维、关鹏飞、项磊、裴冉、岳荣、李青莲），其余为空，属未定，不是无人。
- 玄部所发凭照定名**灵牒**。四表旧写「灵蹀」，「蹀」为「牒」之形近误字，**2026-11-05 作者裁定全库改用「灵牒」**，档案与正文一律照此。
